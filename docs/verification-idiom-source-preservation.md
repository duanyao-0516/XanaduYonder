# 成语资料保留与对局结束规则验证

日期：2026-10-30。基线：`8b185db0f26220ce7880ae03c9f8b589bfd1d848`。工作分支：`p/duanyao.0516/feature/idiom-local-versus`。以下为本次代码和资源的验证结果，不沿用此前版本的验收结论。

## 当前规则

- 清洗只统一结构、合并词条身份，不判断哪个词库释义正确。每条来源的原拼音、释义、典故、出处和例句分别保留，详情页按来源显示；生词本保存展开后的完整资料快照。
- 所有未使用且符合当前接龙规则的词保留选择机会。普通/到期复习与其他合法候选按 95%/5% 分支，优先分支内普通/复习按 80%/20%。不存在的池不参与抽取；普通后继、熟悉度和复习冷却只影响优先级或权重。
- **自动结束的唯一依据是完整词库中没有任何未用过的合法接法。** 推荐池为空、后继不常用、复习未到期或提示用尽均不能自动结束。允许用户主动认输或主动结束本轮。
- 每名人类玩家每局三组新提示；第三组仍可选择、发送并继续。当前方用尽后按钮变为“认输”，双人合计最多六组。认输与无词可接的弹窗说明对应一方及胜方。
- 同音按完整来源读音保留首尾配对，不能跨来源拼接首尾音。无可解析读音仍能用于同字模式；同音模式给出明确提示，不猜补读音。
