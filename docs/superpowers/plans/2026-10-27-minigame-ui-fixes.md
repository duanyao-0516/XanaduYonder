# 小游戏界面修正

基线：2026-10-27 拉取的 `origin/master`，`128e7cc`。用户已明确指定布局、图标和计数语义；沿用现有绿色色系及 UI 工厂。

1. 旸了个旸：在 `SheepBoardGeometry` 限制小布局被整体放大的比例，使教学牌面与挑战牌面大小一致，保持宽高比、遮挡和居中；用现有牌面几何检查覆盖教学与挑战。
2. 跳一跳：`JumpPage` 顶栏大厅右侧放共享 Restart 图标，设置左侧放共享 Book 图标，移除底部两个文字按钮，保留原回调。
3. 数独：`SudokuPage` 对局/选关顶栏复用共享 Home、Settings、Book；对局左侧采用 Back + Restart。撤回、橡皮、铅笔、提示使用同色系网格图标，提示为铃铛；保留状态和配额反馈。玩法使用现有居中对话框的半透明遮罩，保留暂停、恢复和输入隔离。进度以原本可填写格中的非零值数量/空格数量显示，候选不计入，错误填写也算已填写。删除底部重复按钮和数字说明，将说明移入玩法。
4. 大厅：顺序改为 2048、跳一跳、旸了个旸、合成大西瓜、成语接龙、数独；同步页面上实际显示的序号。

验证：各受影响游戏的现有规则、布局、会话测试；Unity 实际 UGUI 渲染和弹窗输入检查、截图；共享图标网格检查；Android 构建。独立交叉审查最终 diff。编译、编辑器表现和真机验收分别报告。保持原目录分支与未跟踪设计稿不变，不修改游戏规则；存档变更仅限下述追加需求中的兼容字段。

## 同轮追加的大厅修正

- 2048 卡片改用浅绿色背景、深绿正文与统一主按钮；成绩行显示最高纪录和跨重开保留的最高数字。旧 schema 1 兼容增加 `bestTile` 字段，旧档从当前保存盘面的最大值初始化，新增真实序列化与磁盘回归。
- 数独卡片成绩区显示总完成数和四档完成数；为保证 500/500/500/500 时可读，分两行显示。统计直接来自已验证的完成记录，不新增缓存。
- 数独难度下拉菜单整体圆角、内部方角选项，采用区别于关卡的奶油/浅沙色并留出边距。
- 大厅导航下沿从 132 调整到 108；底部固定状态文案移到滚动内容的离线说明下一行。其他游戏保留原状态区。
- 实际截图发现自定义图标在编辑器缺少 CanvasRenderer；两个图标组件显式声明依赖，并用真实渲染像素检查覆盖，避免仅检查生成的网格而漏掉不可见图标。
