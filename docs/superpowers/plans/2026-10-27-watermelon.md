# 06 合成大西瓜实施计划

依据同日设计和用户完整开发授权执行。

1. 调研固定版本原项目玩法，导入 33 张原始 PNG 和 4 个音效，核对哈希、来源与 Unity 导入配置。
2. 测试先行实现独立 Core 模型：确定性队列、无效操作不变、原子合并、最高等级、危险宽限和严格快照。

6. 执行核心/存档/素材检查、Unity 构建、设备交互和续局验证，独立代码复核并修复发现的问题。
