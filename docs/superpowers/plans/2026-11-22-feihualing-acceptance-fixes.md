# 飞花令验收修订计划

> 使用独立工作树 `feihualing-game`。当前验收确认的问题与新规则由本计划覆盖。

## 改动与验证

- [x] 先登记每类至少 11 张令题，保留既有题卡标识，再从固定提交的唐诗、宋诗和宋词全部正文分片重导出。优先选入核对过出处的名篇，逐条审核主题句。检验《大林寺桃花》可答「山」与「花」，验证所有题卡和导出可复现性。
- [x] 学习中的离线陪练由设置开启，默认关闭。已开启时玩家有效作答后陪练接一句。提示展示邻句或有关联的诗句，展开仍在原弹窗内，目标句保持遮盖。
- [x] 单机竞技改为不计时的人机轮流接句。双人竞技由同机两人轮流接句，保留小局与换先手。竞技当前方接不下去则对方获胜。原时间和比分规则移到竞速。纯规则测试覆盖交接、无计时、主动认输、恢复和句库耗尽。
- [x] 小图标改用大厅绿线和五瓣轮廓，保留单列大卡的「诗」字印记。通过真实 Unity 页面检查三种目标、提示、设置与图标。
- [x] 保持本地数据流，缩短首次进入时的解包与索引时间。对同一诗库测量旧、新读取器，并测扩容后首次读取。v2 存档保留 v1 原始文件，继承可映射的选项和草稿，旧版成绩留在对应词库的记录里。
- [x] 生成标准 ARM64 测试 APK，复核无联网权限、和主线基线的包体差以及现有大厅和成语接龙回归。安装到用户连接的手机，核实前台启动供人工验收。
