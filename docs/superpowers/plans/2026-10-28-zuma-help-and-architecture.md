# Zuma 导航、玩法说明与架构核查

**Goal:** 在已有隔离分支增加用户指定的两个 Xanadu 样式按钮和完整玩法说明，放大瞄准提示，解决验收包 Development Console，并基于源码说明合集隔离边界。

**Architecture:** 规则和存档保持原协议；帮助内容、帮助视图独立文件，由 ZumaPage 路由和 ZumaView 持有弹窗。编辑器构建负责开发/验收模式，不能通过隐藏日志来掩盖异常。整体架构以只读审计为主，不借本次 UI 改动全面重构宿主。

**Tech Stack:** Unity 6000.3.27f1、C#、UGUI、已有 Noto 中文字体、Android ARM64/IL2CPP。

用户已明确批准本轮布局与功能：选关页左上角“返回大厅 / 玩法说明”，采用 Xanadu 样式；说明列出英文、中文、作用，并讲解发射、回退、金币、换球和难度。补充要求为手机瞄准线稍微放大。
