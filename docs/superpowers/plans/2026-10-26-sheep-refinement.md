# 旸了个旸玩法与品牌修订

**目标：** 按用户的三项反馈取消道具次数配额、改善棋盘与卡槽布局、替换 APP 图标和启动标识。版本继续为尚未发布的 0.3.0。

**边界与实现：**

- 移出、撤回、洗牌不限使用次数。移出区仍为6格，撤回仍针对最近一次未消除的取牌；三消、移出、洗牌会结束该次撤回记录。复活每关一次。历史 used 字段仅记录使用过，不作为这三个道具的配额，保持旧存档可续局。
- 旧布局0..2的几何及牌ID保持不变；新增12种有空隙的分离牌堆，包含双岛、三岛、四岛和分叉结构及错位层。新挑战关只选择新布局，连续重开排除上一布局。生成解法仍以真实核心重放验证。
- 棋盘高540→630；移出区顶部832→888；卡槽顶部958→1008。卡槽标题顶部从-6改为10，牌槽顶部46，背景高136，保证上下内边距。底部工具、操作与状态随之调整并验证短屏。盲堆显示扇开的空白牌背。
- 原样导入 `Downloads/XY_logo.png`。通过 Unity 官方 SplashScreen/API 设置自有标识及白底，禁用 Unity 标识；配置 Android Legacy/Adaptive/Round 图标并检查 Android 12 系统启动窗口。保持已有发布签名。

**执行与验证：**

- [x] 规则：重复使用、历史状态续局、移出区容量、一次复活、JSON和磁盘恢复的红绿测试。
- [x] 布局：旧几何指纹不变，新布局多结构、有间隙、无同层重叠、边界正确、连续重开不同、多种子完整解。
- [x] UI：修改卡槽内边距、各区位置与工具文案，按图案实际验证点击和遮挡。
- [x] 品牌：原图哈希一致，Unity编辑器配置和生成的Android资源验证；录制真正冷启动确认只出现自己的图标。
- [x] 独立代码审查；Unity开发包和正式签名包编译；Android真机和短屏模拟器验收。
- [x] 覆盖安装前备份三游戏现有存档；测试后恢复精确用户进度，验证旧局能继续，新开局才用新样式。
- [x] 更新说明与验证记录，保存本地提交和可安装包。
