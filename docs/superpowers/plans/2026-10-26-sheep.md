# 旸了个旸 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 把「旸了个旸」作为第三款可离线保存的完整游戏接入合集，并将大厅改为固定卡高的滚动列表。

**Architecture:** `Core/Sheep` 独立实现规则与可解生成；`Runtime/Sheep` 实现严格存档边界与 Unity 表现。AppController 只添加游戏导航和统一生命周期钩子，不改旧游戏存档协议。

**Tech Stack:** Unity 6000.3.27f1、C#、Unity UI、Newtonsoft JSON 13.0.2、.NET 10 独立测试、Android ARM64。
