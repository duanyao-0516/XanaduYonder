## 稳定接口约定

纯 C# 命名空间 `XanaduYonder.Core.Sudoku`。

```csharp
// 题库任务所有
public sealed class SudokuPuzzle {
    public string Id;
    public int Difficulty; // 0..3
    public int Level; // 1..500
    public int[] Givens;
    public int[] Solution;
}
// SudokuCatalog.Parse(string text), Puzzles, Get(int difficulty, int level), Count(int difficulty)
// SudokuSolver.CountSolutions(int[] givens, out int[] solution), max 2
// SudokuHintEngine.Find(SudokuPuzzle puzzle, int[] values, int preferredCell)
// -> SudokuHint { int Cell, Digit; string Technique, Explanation; int[] Evidence; bool IsDirect; }

// 核心任务所有
public enum SudokuPhase { Playing, Won, Lost }
// SudokuGame(SudokuPuzzle), SudokuGame(SudokuSnapshot)
// GetSnapshot(), Puzzle, ValueAt(cell), NotesAt(cell), IsGiven(cell), IsCorrect(cell)
// RemainingCount, RemainingDigit(digit), CanUndo, Errors, HintsRemaining, Revision, Phase
// EnterValue(cell,digit), ToggleNote(cell,digit), Erase(cell), Undo()
// -> SudokuMove { Changed, Mistake, RejectedNote, Conflicts, Cell, Digit, Phase }
// SpendHint() -> bool; ApplyHint(cell,digit,expectedRevision) -> SudokuMove
// Snapshot: Puzzle, Values[81], Notes[81] (1 << (digit-1)), Mistakes, HintsUsed,
// Revision, History (each before-values/notes), Copy(), TryValidate(out string).
```
