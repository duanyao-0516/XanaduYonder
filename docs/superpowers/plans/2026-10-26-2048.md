# 2048 首版 Implementation Plan

> **For agentic workers:** Use subagent-driven-development for independent tasks, followed by specification and quality review.

**Goal:** 配置 Mac Unity/C# 环境并交付 Android 真机可玩的离线 2048。

**Architecture:** 纯 C# 规则和状态由独立测试覆盖；Unity UGUI 负责显示、输入、反馈及生命周期；版本化 JSON 存储完整对局和设置。

**Tech Stack:** Unity 6.3 LTS Apple Silicon、UGUI、C#、Android IL2CPP/ARM64、.NET 10 测试工具。

## Tasks

- [ ] 安装 Unity Hub、固定的 Unity Editor 及 Android 模块；安装用户目录 .NET SDK 与 VS Code Unity 扩展。验证真实版本、许可与设备。环境工作不依赖游戏实现，可并行。
- [ ] 先在 `Tests/Core/` 编写并运行失败的规则契约测试，再实现 `Assets/Scripts/Core/`。覆盖 `[2,2,2,2] -> [4,4,0,0]` 得分8、`[2,2,4,0] -> [4,4,0,0]` 不二次合并、四方向、无效移动不随机生成、胜利/失败和非法快照拒绝。命令 `scripts/test-core.sh` 必须零失败。
- [ ] 创建 `Packages/manifest.json` 与 `ProjectSettings/ProjectVersion.txt`；配置 `.asmdef` 隔离纯规则与运行时。编辑器生成启动场景并提交真实 `.meta` 与工程配置。
- [ ] 实现 `Assets/Scripts/Runtime/` 的大厅、棋盘、设置、确认/胜负弹窗；输入仅在棋盘且非动画/弹窗时生效。根据规则返回的移动轨迹播放动画，最终显示以规则状态为准。
- [ ] 实现本地存档边界：真实 JSON 反序列化后校验 schema、游戏标识、16格、合法数值、分数与胜利标志；临时文件加替换写入；持久化失败应可见且不中断游玩。测试往返、损坏和重启恢复。
- [ ] 实现 `Assets/Editor/` 构建入口和 `scripts/build-android.sh`；Android包名 `com.duanyao.xanaduyonder`，版本 `0.1.0`，竖屏，ARM64，离线运行。批处理必须在失败时返回非零。
- [ ] 跑规则测试、Unity导入编译、APK构建；指定序列号安装物理机，开始日志采集后执行验收场景，保存截图和日志到被忽略的 `artifacts/`。
- [ ] 独立规格审查与代码审查；修复问题后仅重跑相关测试及受影响构建/设备步骤。
- [ ] 更新 README、环境/构建说明和验证报告；核对 Git 忽略规则、许可证和最终差异。本地提交完成的工作，不推送或发布。
