# Gomoku Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Execute the user's approved design continuously. Independent file ownership permits parallel modules; the coordinator owns integration and Unity execution.

**Goal:** Deliver the approved offline Gomoku game in its existing isolated worktree.

**Architecture:** Pure C# Core owns rules/search. Runtime Session owns turns and request generations, storage owns strict persistence, Board owns presentation/input, and Page integrates shared shell services.

**Tech Stack:** Unity 6000.3.27f1, C# 7.3-compatible production code, .NET 10 console checks, Newtonsoft.Json 13.0.2.

## Shared contracts

Core namespace `XanaduYonder.Core.Gomoku`:

```csharp
public enum GomokuStone { Empty=0, Black=1, White=2 }
public enum GomokuState { Playing=0, BlackWon=1, WhiteWon=2, Draw=3 }
public enum GomokuMode { HumanVsAi=0, Local=1 }
public enum GomokuDifficulty { Easy=0, Normal=1, Hard=2 }
// GomokuGame: Size=15, CellCount=225; new empty board; Restore(int[] moves).
// Properties: State, ToPlay, MoveCount, LastMove, WinningLine (defensive int[]).
// Methods: GetCell(int), TryPlay(int), Undo(int), ExportMoves(), Copy().
// GomokuCoordinates.Format(int index), TryParse(string, out int index).
// GomokuAi.FindMove(GomokuGame, GomokuDifficulty, CancellationToken,
//                  GomokuSearchOptions options=null) -> GomokuAiResult.
// Result: Index, CompletedDepth, Nodes, ElapsedMilliseconds.
```

Runtime namespace `XanaduYonder.Runtime.Gomoku`: data and Session expose pure C# types. `GomokuSessionData` contains SessionId, Mode, Difficulty, HumanStone, BlackPlayer (1 or 2), Moves. `GomokuSaveData` contains SelectedMode, PreferredDifficulty, PreferredHumanStone, PreferredBlackPlayer, two Slots. `GomokuSession` exposes Game, Mode, Difficulty, HumanStone, BlackPlayer, SelectedIndex (nullable), Paused, CanSelect, NeedsAi, CanUndo; TrySelect, ClearSelection, ConfirmSelection, Undo, Pause, Resume, SetForeground, SetBlocked, BeginAi, AcceptAi(request,index), CancelAi, Export. Constructor from data starts paused; static Create(mode,difficulty,human,blackPlayer) creates a ready session. `GomokuAiRequest` supplies a Game snapshot plus identity/revision validation. `GomokuSaveStore` supplies SavePath, LastLoadStatus, Load(out warning), TrySave(data,out error).

Board contract: `internal sealed class GomokuBoardView` constructed with RectTransform surface; event `Action<int> Selected`; `bool Interactable`; `Render(GomokuGame,int?)`, `CancelInput()`. It must neither commit moves nor own Session. Axis labels use the same mapping as Core.
