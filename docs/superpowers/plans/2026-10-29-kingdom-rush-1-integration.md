# 王国保卫战初代接入实施记录

**Goal:** 将 FL 初代完整内容接入 Xanadu 大厅，编译并安装到用户指定的 OPPO，供用户测试。

**Architecture:** Unity 大厅调用内部 Android Activity，沿用匹配的 SDL3/LÖVE 与 Lua 游戏代码。初代 profile 控制加载和存档边界，离线媒体由可复现脚本筛选并生成独立内容 AAR。

**Tech Stack:** Unity 6000.3.27f1 / C#、Java / JNI / ARM64、LuaJIT、Python ZIP 与资源清单。

日期：2026-10-29。用户已授权开发、编译并安装到 USB 连接的 OPPO；游戏测试由用户执行。当前基线为 origin/master `8b185db`（v0.7.0，十七款游戏），分支 `p/duanyao.0516/feature/kingdom-rush-1`。

## 内容与边界

- 保留 FL8.0.5 初代 32 关（45–76）、三种模式、13 初代英雄、初代防御塔及关卡专用设施，只显示中文。
- 按实际引用打包图片、音频、字体、动画和关卡数据；其他代的独立战役、英雄和塔不接入。初代扩展关确实复用的素材保留并记录依赖来源。
- 保留原 Lua 玩法与图形系统，Unity 只负责大厅、公共设置和入口；内部 Android Activity 承载游戏，退出返回大厅，存档独立。
- 素材全部离线内置；采用已实测的分档压缩，不以缺素材/静音/空实现换取目标体积。最终体积以本次 APK 为准。

## 文件职责与执行命令

- `Assets/Scripts/Runtime/AppController.KingdomRush.cs`：第十八张大厅卡片、保存后启动、失败提示与按钮恢复。`KingdomRush/KingdomRushLauncher.cs`仅负责 `open(Activity, sound, haptics)`、`isRunning()`、`getLastError()` 边界。
- `ThirdParty/KingdomRushRuntime/`：固定源码版本、匹配原生库、生命周期补丁与真实 JNI；`scripts/kingdom-rush/build-runtime.py`编译运行库 AAR，并将已生成 `game.love` 放入内容 AAR。
- `ThirdParty/KingdomRushContent/`及`scripts/kingdom-rush/build-content.py`：初代 profile、依赖清单、源码补丁、压缩资源与逐项来源。原始输入使用`--source-apk`，前期编码结果使用`--compression-source`。
- `Assets/Plugins/Android/AndroidManifest.xml`：内部游戏 Activity 与保持任务栈的启动入口；生成 AAR 和元数据不提交。
- `Assets/Editor/ProjectBuild.cs`的`BuildKingdomRushPreview`及`scripts/build-kingdom-rush.sh`：非 Development、独立包名构建，恢复原项目设置。
- `scripts/kingdom-rush/verify-apk.py APK --aapt AAPT_PATH`：核对 APK 包名、启动入口、无联网权限、ARM64 库、内容哈希及 ZIP 完整性；不启动游戏。
- 安装使用`adb -P 5039 -s 3B6F4NE8A66ZXTRL install --no-streaming -r APK`，随后以包管理器只读信息确认版本和安装路径，不追加自动启动或操作测试。
