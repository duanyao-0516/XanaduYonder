# 旸了个旸设计

用户要求在离线小游戏合集中完整接入经典叠牌三消玩法，使用提供的素材，游戏显示名称为「旸了个旸」。内部稳定标识保留 `sheep`，与素材名称和源码命名解耦。用户已明确确认另行获得游戏开发授权；素材包内的 PDF 不作为游戏用途许可依据。

## 玩法与来源

- 第一关为 18 张牌、3 种图案的教学关；第二关为 144 张牌、16 种图案的挑战关。数量与具体布局是本项目的离线设计。
- 点击没有被更高层牌覆盖的牌，移入 7 格卡槽。同图案 3 张立即消除，先结算三消，再判断满槽失败。所有棋盘牌、卡槽牌、移出区牌都消除才胜利。
- 挑战关包含多层主区域、浅层保留区域、左右盲堆。盲堆只显示顶牌图案和剩余深度；遮挡判定按卡片实际占用的二维面积计算，边缘接触不算遮挡。
- 移出：卡槽前三张转移到旁边的移出区，之后可逐张重新选回卡槽。撤回：将最近一次、仍未被消除的取牌退回准确原位。洗牌：只重排棋盘上的剩余图案，保留数量、布局与遮挡关系。
- 三种道具每关各免费一次。失败后另有一次免费复活，作用为移出卡槽前三张；移出区最多 6 张。失败时若仍可移出或撤回，也允许使用对应道具恢复游戏。
- 教学关胜利进入挑战关；挑战关胜利完成一轮，累计通关数增加一次。通关后的“再闯一轮”从教学关开始；“重开本关”保留当前关卡编号并重置本关棋盘和工具。

[2022 年现场报道](https://finance.sina.cn/2022-09-24/detail-imqmmtha8537675.d.html)支持 7 槽三消、两关难度递增的经典结构；[2022 年官方攻略转述](https://finance.sina.cn/2022-09-15/detail-imqqsmrn9110556.d.html)支持移出前三张、撤回、洗牌、一次复活的机制；[开发商发布的通用攻略](https://game.xiaomi.com/viewpoint/1647049200_1745293797306_13)支持深层主攻区、浅层保留区、盲堆与复活作用。后者位于较新的产品社区，本项目只取通用规则，不引入其星球功能。

撤回最近一手已三消时禁用、执行其他道具清除撤回记录、复活与移出共用最多 6 张可见的移出区，是本项目明确采用的边界约定，不声称复刻原版未公开的实现。所有道具免费，无广告、分享要求、登录、网络、地区榜或云存档。

## 可解关卡与状态所有权

纯 C# `Core/Sheep` 持有游戏规则。固定布局用 `Level/LayoutId` 派生坐标，存档不保存任意几何数据。初始局先生成合法的拓扑取牌顺序，再交错分配三张组，限制未完成组占用，使真实核心能逐步重放解法直至获胜。生成器返回解法供测试使用真实核心重放；多种子测试用于验证可解性，运行时不另行执行通用搜索求解；可解初始局不保证任意玩家走法可解，普通随机洗牌也不承诺一定救活。

`SheepPage` 拥有局内 UI、动画、工具操作、结果展示和胜利计数；`AppController` 仅负责进入、返回、设置模态层、暂停、声音触感偏好和统一保存时机。取牌先提交规则和保存，再展示动画。连续快速点击可接续已提交状态，不把动画期间的合法操作静默丢弃。

## 存档

独立 `sheep-v1.json` 使用 schemaVersion 1、gameId `sheep`。保存牌图案、位置枚举、卡槽/移出区顺序、随机状态、关卡布局、道具次数、最近取牌来源、累计通关数和胜利已计数标记。累计通关数以十进制字符串保存，避免 JSON 数值精度差异。

严格检查 JSON 字段集合、重复键、类型、枚举、数组长度、牌数守恒与状态一致性；限制文件大小 128 KiB、深度 8。使用 `.tmp` 写入和 `.bak` 回退，损坏主档尝试备份，不覆盖其他游戏存档。已有 2048 与跳一跳协议保持兼容。

## 大厅与游戏表现

大厅固定顶部品牌与设置，下面介绍、三张卡片和说明在同一个纵向列表中滚动。每张卡保持 350 设计单位高度，卡间距从 32 调为 24；不随屏幕或游戏数量压缩。底部状态区域在滚动视口外，返回大厅保留列表位置。新卡显示「03 / 层层三消」「旸了个旸」「翻开一层，凑齐三个。」和累计通关数。

游戏页沿用米白、绿色配色及提供的 16 种经典图案与独立牌底。清楚展示当前关卡、剩余牌、可选/遮挡状态、7 格槽、移出区、工具剩余次数、结果与重开入口。布局适配既有安全区域，状态栏和手势区域不得遮挡操作。

## 验收

纯规则测试覆盖遮挡、同层/边缘、三消优先、7 槽失败、所有区域清空、各工具和复活、撤回来源、快照隔离和多种子解法重放。存档测试使用真实 Newtonsoft JSON 和文件系统验证类型/损坏/备份/写失败。Unity Android 编译后在已连接手机验证两关、工具、续局、声音触感、后台恢复、返回大厅与列表滚动，同时回归旧游戏并保存其真实用户进度。独立审查后记录本地 APK 和验证范围；本次任务不自动发布新 GitHub Release。
