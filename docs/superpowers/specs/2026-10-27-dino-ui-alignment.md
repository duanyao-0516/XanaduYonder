# Dino UI 对齐修订

用户于 2026-10-27 实机反馈后明确：游戏名为 Dino；页面布局、字体及颜色参照既有跳一跳／2048；竖屏缩短空白跑道，横竖屏均留边并使用圆角矩形，优先保证视觉协调。本修订替代前版规格中的全宽跑道与“小恐龙”展示名称。

- 使用 UiFactory 的 NotoSansCJK 字体及 Ink / Muted / Paper / Accent。图标导航、品牌19、标题63（横屏48）、分数标签19及数字37均来自既有页面层级；数字不补前导零。
- 竖屏跑道 x56、宽608、高320；横屏同样两侧留56，以实际剩余高度排布。跑道真实使用 UGUI Mask 裁剪天空与精灵，不能只画圆角外框。
- 跳跃／下蹲使用同款标准按钮，说明放到按钮外。暂停、方向与重开仍通过既有确认和冻结流程。
- 所有物理视野、速度上限、窗口安全校验和显示映射均取圆角卡片的实际宽度；不修改 Core 运动、碰撞或计分规则。
- 弹窗对齐公共596宽、32内边距、33号标题、Muted正文和0.48遮罩；保留独立横屏排版以避免竖屏缩放。
- 大厅、页面、帮助、错误提示和测试应用标签统一 Dino；应用ID及存档字段、文件名保持兼容。

实现和验证只在 chrome-dino 工作树进行。先检查真实 Unity 画面（两种竖屏高度、普通与窄横屏、选择页／帮助／设置／暂停／夜景），再执行状态与合集回归，构建并更新独立 OPPO 测试包。
