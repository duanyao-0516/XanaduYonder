## 承载选择

推荐：沿用王国保卫战的外部 Activity 接入模式，新增游戏专属 Android WebView Activity，内置并执行原版 LayaAir 3.3.13 / Spine 3.7 客户端。Unity 拥有大厅、公共设置、启动互斥与返回；Android 宿主拥有本地资源加载、方向、全屏、前后台与系统返回；原游戏拥有规则、AI、游戏状态、原版表现及本地存档；离线适配层只修改平台依赖、明确的经济入口、资源缺口与宿主生命周期接口。

另两个方案：完全重写 Unity C# 会扩大规则和动画偏差风险；嵌入完整浏览器运行库会增加包体和维护负担。当前需求使用 Android 系统 WebView 承载原引擎即可。

## 大厅与宿主

- 大厅三种视图均新增 `zhaoyun-adou` 入口，序号 21。单列使用原游戏标题/角色素材，双列与目录使用清晰的小图标；按现有尺寸和资源加载规则接入。
- 独立全屏竖屏 Activity，游戏画面保持原版布局，不加常驻宿主工具栏；玩法说明可在原游戏本地入口呈现，原游戏暂停和设置继续可用。WebView 和游戏画布直接铺满屏幕，不为返回手势、刘海或底部区域整体留白，也不预先搬移原控件；系统边缘手势由 Android 正常处理。仅当真机证明具体按钮被遮挡或无法点击时，再修正该按钮。
- 把已有「王国保卫战运行中」门禁收敛为 shell 的「外部游戏运行中」门禁，避免启动窗口交叉、后台大厅误触。不得把游戏业务塞入公共 UI 基类。
- 第一次已提交的系统返回显示“再返回一次回到大厅”；2秒内第二次已提交返回保存长期进度、结束当前游戏并返回大厅，超时重新计数。取消的预测返回手势不计数，失焦/后台重置计数；不通过WebView.goBack切换历史，不叠加第三次确认。退出释放WebView、音频和回调。进入失败给出可恢复的返回入口。
- 公共声音开关作为总开关，与游戏内部音乐/音效偏好共同生效。无需新增触感或其它权限。

## 完全离线的边界

- 发布包不含 `INTERNET`、网络状态、存储、通知、相机、麦克风、定位、广告 ID 等新增权限。合集现有震动权限不因本游戏扩大用途。
- 本地 HTTPS 同源路径映射到 APK 内 assets；只接受明确的游戏目录、GET/HEAD 与已登记文件。未知资源返回明确失败，不回退互联网。
- 禁止外部页面跳转、弹窗、下载、文件选择、WebView 权限请求及远端脚本；禁用通用文件访问。WebView 网络禁用和页面 CSP 双重限制外部连接。
- 发布内容不含 4399 外壳/SDK、账号登录、授权头像、云存档、分享、平台排行榜、反馈外链、原平台隐私弹窗和导流公告。素材版权与来源留在开发文档/第三方说明，不伪装成原作者工程。
- 构建输入固定原始资源哈希；生成离线包的转换须可重跑、校验匹配次数并输出变更/资源清单，不依赖 `/tmp` 或研究时浏览器缓存。

## 离线游戏规则

| 原入口 | 推荐离线行为 |
| --- | --- |
| 开局体力与广告/分享补体力 | 不再限制开局，移除体力补充入口与相应提示 |
| 普通胜负结算 | 保留原金币、段位、武器碎片及武将碎片规则；标准胜/负金币为 20/5 |
| 看广告双倍金币 | 移除双倍入口，正常领取标准奖励 |
| 商店随机广告商品 | 使用该商品原金币价格与升级等级价格；保留售罄、容量和刷新规则 |
| 广告/分享轮盘抽奖 | 隐藏；已核对奖池与普通商店同源，没有独占武器、武将或碎片 |
| 战斗铲子/推土机的后续广告次数 | 各保留每局一次明确的免费援助，用尽即禁用，不显示广告按钮 |
| 段位页 | 保留个人段位和本地昨日段位奖励，移除全国/省份榜、授权与联网文案；奖励领取和已领取标记必须同一次持久化提交，原4399默认隐藏入口的事实记录在适配说明中 |
| 正常道具与成长 | 保留包子/续命丹/大补丸等游戏道具，保留 Boss 掉落、累计合成解锁及全部武器/武将成长 |
| 武器背包与普通碎片的第 3 天门槛 | 第一天开放完整武器能力；原有 4 类基础武器与已领取标志一次提交，保存失败重新载入重试，不重复赠送 |
| 连续登录 3/7 天头像 | 两个头像开局可选；其他成就条件及真实登录统计保持 |
| AI 专属武将的第 3 天门槛 | 取消天数条件，仍需对手段位至少 50，原概率和玩家碎片条件保持 |
| 按日期轮换的地图 | 按累计完成局数每 7 局轮换四张地图，前 21 局保持原首日顺序；不修改全局时间或增加选图入口 |

不通过假广告 SDK 或通用「广告成功」回调暗中发奖；改动应落在明确业务入口和本地规则。当前对手仍为原本的本地 AI，玩法说明明确这一点。

首日开放只取消功能等待，不提前结算每日奖励或赛季，不修改道具有效期、商店刷新、新手保护和 AI 难度。原武器系统通过碎片获取及换装提高攻击，没有独立武器等级升级按钮。

## 缺失资源处理

- 龙胆亮银枪枪头特效：复用已存在的普通长枪特效。其伤害与碰撞计算独立，保持原武器数值。
- 商店 `light3.png`：仅使用现存的 light1/light2。
- 商店发光描边 shader：不创建该可选装饰效果；保留按钮本身与点击区域。
- 奖励碎片图和结算页未解析 UUID：替换为本包中语义一致的奖励图标；以实际节点用途选择，不插入透明占位。
- 启动画面：使用已存在的标题/背景；删除缺失 splash 引用。
- 两个未使用 shader 注册及调试场景入口：从发行配置/可达入口移除。
- 最终包要求可达资源引用无未处理缺失，不能以「原站也缺」作为成品例外。

## 存档与生命周期

- 固定游戏 origin 与独立存档命名空间，持久化原有段位、金币、道具、武器/武将和设置。升级不能因路径或 host 变化丢档；读写失败可观察且不清空现有进度。
- 不引入账号、云同步或远程存档；不读写其它小游戏存档。
- 后台、失焦、第二次返回退出时，显式调用原游戏暂停入口并停止计时/音频，不能只依赖 WebView.onPause 或 visibilitychange。恢复前台保留原暂停状态，战斗需明确继续。
- 原版没有完整战斗快照。当前接入保留这一边界：前后台切换保留现有战斗；返回大厅或进程被回收后回主菜单，长期进度保留，不宣称跨进程恢复战场。离开前按原游戏退出/结算语义处理，不重复扣除或发放奖励。
