# XanaduYonder 2048 首版设计

目标：在本地 Mac 建立 Unity/C# Android 开发环境，交付可离线运行并在已连接 Android 真机验证的首版。范围依据 README 与本次用户明确授权。

## 产品与交互

- 竖屏、暖白背景与深绿色强调色；中文界面，数字棋盘保持高对比度，适配安全区域。
- 大厅只展示可玩的 2048，进入时继续已有对局。公共设置包含声音和触感开关。
- 标准 4×4 规则：初始两个随机方块，每次有效移动后在空位生成 2（90%）或 4（10%）；每个方块一次移动最多合并一次，分数增加合并后的值。无效移动不生成新方块。
- 滑动棋盘操作；编辑器支持方向键。显示当前分数、最高分、合并与生成动画。
- 首次达到 2048 提示成功，可继续挑战；无合法移动时提示结束，可以重开。
- 重开需确认；Android 返回键与页面返回按钮保留对局并返回大厅。应用失焦/进入后台时暂停交互，恢复时保持棋盘。
- 每次有效移动、设置变化及生命周期退出前保存。游戏存档使用稳定标识 `2048`、schemaVersion=1，设备本地存储。损坏或未知版本存档安全回退到新对局，不崩溃；不做旧版本迁移。
- 不接入广告、登录、网络、云存档、排行榜服务、小游戏平台 SDK。

## 实现边界

采用 Unity UGUI 构建简单 2D 界面；相比重型 3D 模板减少不需要的依赖，相比网页封装保留 README 确定的 Unity/C# 技术路线。首版只建立当前需要的大厅与游戏边界，不创建复杂插件框架。

- `Assets/Scripts/Core/`：不依赖 Unity 的规则、状态与数据校验；随机源可注入，便于确定性测试。
- `Assets/Scripts/Runtime/`：Unity UI、滑动识别、动画、音效/触感、生命周期与 JSON 文件读写；规则模型是唯一棋盘状态来源。
- `Assets/Editor/`：创建启动场景、固定 Android 构建配置、命令行构建和项目验证。
- `Tests/Core/`：使用与 Unity 相同的 C# 源文件进行独立 .NET 测试，涵盖四向移动、一次合并规则、随机生成、胜负、存档校验。
- `scripts/`：环境检查、测试、Unity 批处理构建和指定设备安装；工具路径允许环境变量覆盖，不提交机器凭据。

## 验收

1. Unity 编辑器版本、Android 模块、SDK/NDK/JDK、C# IDE 以及 .NET 测试工具均有实际检测证据。
2. 规则测试通过；Unity 工程实际导入和编译；APK 实际构建通过。
3. 指定物理设备验证大厅进入、滑动与合并、分数变化、无效滑动、设置、暂停返回、退出重启恢复、重开确认；验证胜利及失败分支，并保留截图/日志。
4. 独立审查规则、存档契约和生命周期，修复确认的问题。
5. README 记录可复现操作及已完成验证，区分自动测试与真机观察。仅本地开发与安装，不发布商店、不推送远端。
