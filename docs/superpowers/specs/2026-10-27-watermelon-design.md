# 06 合成大西瓜

用户要求在此独立工作树完整接入编号 06，编号 05 由其他工作树开发数独。基于 master b066953；保留大厅现有卡片高度和滚动。素材使用用户已授权的 https://github.com/idootop/watermelon ，固定参考版本 8af7d8892c0218206a579d4b5717facab2d26d6e，原创 C# 实现，不复制其 Dart/AGPL 代码。

## 玩法和体验

竖屏容器内拖动瞄准、松手投球，点击也可投放。随机预览等级为 1–5；相同等级接触后消耗两个球并合成下一级，加合并前等级分数。共 11 级，达到最高等级庆祝后可继续挑战。提供当前球、下一颗、分数、最高分、警戒线、暂停、重开、图鉴和玩法说明。连续投放间隔 0.38 秒，不缓存越过冷却的手势。

水果、表情、校徽三个主题即时切换，不重开、不改变球半径/位置/队列/分数。校徽圆形遮罩，等级只是素材顺序。已有接触且年龄超过 1.2 秒的低速球顶部持续越线 2 秒后失败；下落、弹跳和合并有宽限。合并先于同一步失败判定。

## 实现归属

- Core/Watermelon：与 Unity 无关的队列/RNG、球身份、原子合并、分数、冷却、越线和快照校验。
- Runtime/Watermelon：Unity 原生 Physics2D 独立场景，固定步长手动模拟，不修改全局物理设置。碰撞回调仅收集接触，统一在模拟后合并。UI RawImage 与物理状态同步。
- 独立 watermelon-v1.json：完整球位置、速度、旋转、接触/年龄、队列/RNG/计时、主题、最高分、胜利确认。严格 JSON 校验，原子写入和备份恢复，不接触其他游戏存档。
- AppController：仅新增 06 大厅卡片和页面生命周期接入。卡片号码显式 06，不占用 05。

暂停、弹窗、返回大厅、后台和失焦立即取消指针并停止物理；保存后恢复原局，不追赶后台时间。单个手指控制投放，控件区域不会触发投球。页面销毁释放独立场景、材质和 UI 生成纹理。
