# 飞机大战接入设计

用户已授权方案合理后直接开发。基线为 origin/master 2586c249（0.9.1），独立工作树 aircraft-fire，分支 p/duanyao.0516/feature/aircraft-fire。原检出及其未提交文档保留。

## 目标和参考边界

以用户提供的 Aircraft+Fire_2.5_APKPure.apk 为玩法和素材参考，以 Unity + C# 重写。APK 提供 Cocos 风格图集、音效及有符号的 ARM 32 位 libgame.so，并非完整源码；可确认的规则记录来源，重写的调参不宣称二进制等价。应用继续离线，不引入 APK 的广告、账号、排行榜 SDK 或 native 库。

## 接入和表现

新增第 20 个入口“飞机大战”，分类“敏捷挑战”。复用同一 LobbyEntry 覆盖双列、目录、单列。单列展示 APK launcher icon，比例及圆角与其他 Logo 相适配；双列及目录使用本项目新增飞机线条图标。

从大厅进入原游戏的竖屏入口菜单，此时不创建或推进对局。菜单提供“经典模式”和“关卡模式”；经典模式可选普通／疯狂进攻，关卡模式固定七关。合集现有 Home、Book、Settings 三个按钮只在入口菜单显示：Home 或系统返回回到大厅，右上角 Book 打开说明、Settings 复用共同声音／触感设置。说明关闭直接回到入口，设置关闭不开始对局；入口切后台再恢复仍停在入口。

选择模式后进入实战。战场挂到 canvasRoot，绕过大厅的限宽 safe design frame；背景全屏满宽，飞机与子弹等比缩放，短屏／长屏按实际可用高度参与规则边界。实战不显示入口的三个导航按钮，也不新增仪表栏；使用原素材暂停按钮，系统返回同样打开暂停。暂停页和结算页的“主菜单”返回游戏入口，切换模式后才开始新局。所有联网、通知、广告、账号、推荐等非游戏本体内容移除，不提取对应资源／SDK。

## 玩法和职责

Core/AircraftFire 拥有固定步模拟、敌机生成/运动、自动射击/碰撞、积分、Boss/波次、炸弹和双发补给、死亡与复活状态。Runtime/AircraftFire 拥有触摸所有权、素材显示、动画/音效、全宽布局和暂停/说明/结算。AppController 只负责入口、共同设置、离页/后台/返回路由。

保留三类敌机（小型、中型、Boss）及原版爆炸动画。图集中 enemy4/5 实际是炸弹和双发降落伞补给，不作为敌机。拖动控制，自动开火；炸弹按钮清场。暂停或失焦停止模拟、清除手势，恢复需明确继续。退出大厅后下一次先回到游戏入口，选择模式开始新局。最高分独立保存到 aircraft-fire-v1.json，明确 schema 和 token 校验、主备恢复、写失败提示，避免影响其他游戏存档。

## 验证

按用户要求控制测试投入：核心规则/存档关键自动化，Unity 编译，三种大厅及全宽页面检查，生成 ARM64 开发 APK。模拟器可用时短时验证入口、拖动/炸弹、暂停及返回。用户负责主要真机玩法/手感验收；不把截图或编译当成设备全覆盖结论。

入口菜单修订需要另行执行生产 UGUI 检查：三种尺寸的入口截图、入口说明／设置／后台恢复、选择模式后实战导航隐藏、暂停和结算返回主菜单，以及既有拖动、终局动画和复活场景。此前直接进入战场版本的检查结果不代表本次修订已验证。
