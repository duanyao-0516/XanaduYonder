# OPPO 手机界面改版试玩

打开独立应用「Xanadu 战争进化史测试」。大厅底部只有一张「战争进化史」卡片，进入后选择一代或二代。正式 APP 和已有存档不受影响。

1. **入口**：两代直接到主菜单，无广告、外链和片头。菜单 Exit 返回大厅；一代无 Extras，二代无网站专属 Insane 难度。
2. **宽屏**：左右大黑边消失，人物比例正常，顶部栏目位于两侧；兵种、炮塔、技能点击位置正确，空白战场可拖动镜头。
3. **暂停**：两代战斗顶部中央都有暂停按钮，点一次即进入暂停页。系统沉浸式与原返回手势保留。一代手机不显示鼠标，暂停显示 PAUSED、Press Screen to resume、Exit；点屏幕恢复，点 Exit 返回大厅。
4. **玩法**：分别出兵、建塔/卖塔、使用技能、进化时代；二代升级、倍速和暂停设置可用。
5. **切换**：返回大厅重选版本、切后台再恢复，不应有残留音乐、卡住或误点。
6. **资源与帮助**：二代 Pop / Xp / Gold 在底部居中，金币末尾完整显示；版本选择页右上角书本按钮可打开并滚动玩法说明。

二代技能沿用原规则：玩家开局充能 60 游戏秒，每次使用后冷却 60 游戏秒；第一时代落石还需 2000 经验。电脑约第 20 游戏秒使用落石时，玩家仍处于开局充能期，并非被电脑施法重置冷却。

有问题时发「第几代、所在页面/时代、操作步骤、预期与实际」，画面或时序问题附录屏最方便定位。最后的效果由你实际试玩验收；本轮按要求不再追加自动验证。
