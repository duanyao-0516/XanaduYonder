# 游戏精简与 iOS 网页游戏适配

用户要求删除经典黄金矿工独立入口、战争进化史、王国保卫战、切水果大师，并确保安装包没有相关代码或资源。经典黄金矿工的源关卡数据和规则迁移到保留的 Unity 黄金矿工。Zuma、飞机大战继续使用已有 Unity 实现；赵云与阿斗、割绳子、只有一道门在 iOS 接入 WKWebView。

## 实现边界

- 原生黄金矿工新增 Source 5 战役，使用源单人 30 布局和双人 30 关共 1,205 个对象；旧 1–4 版本局内存档仍按原规则继续，不重新解释旧版本号。
- 仅保留迁移所需的关卡、规则和美术数据；移除经典版本的网页引擎、Android 包和独立入口。
- 安卓启动中转 Activity 改为平台公共入口，解除对王国保卫战的依赖；保留已有任务复用语义。
- iOS 使用公共 WKWebView 宿主和仅回环地址的资源服务器，各游戏固定端口保证存档 origin 稳定。退出、切后台、恢复按各游戏已有协议执行；割绳子的同步存档接口必须返回实际写入结果。
- iOS 独立 staging 才加入网页资源，Android 继续使用各自 AAR，避免双份内容。逐文件大小和 SHA-256 核验；保留 bundle ID、签名和现有用户数据。

## 执行及验收

1. 封存并逐字段核验黄金矿工源数据，再删除经典入口及源引擎。
2. 分别实施 Source 战役、iOS 宿主、游戏删除和 Android 依赖清理。
3. 收束 staging、编译入口、当前文档和最终产物检查，保留历史记录的时间语义。
4. 运行相关纯逻辑测试、源数据一致性检查和交叉审查；Unity / Xcode / Android 构建串行执行。
5. 对最终 APK、iOS 导出和 app 检查删除项、SO、DEX / 程序集、资源打包清单；实际连接设备检查网页游戏启动、操作、后台、声音、退出和存档。源码、编译和真机结果分别记录，不互相替代。
