# 操作与体验整理（2026-11-08）

基于 0.9.6/build 15 的源码改动，尚未更新 GitHub 既有 Release 资产。贪吃蛇原分支历史合入后，大厅为 Android 26 项、iOS 20 项。

## 操作

- 俄罗斯方块默认左手左右/下移动、右手顺时针旋转；没有上键、逆时针或独立直落键。按住下键加速，同一块内快速三连击下键直落。设置可交换两组按键，暂存位置不变。手势提示只在玩法说明。
- 成语接龙默认开启“双人对战发送固定右侧”：发送在右、提示在左。关闭时随本地双人当前玩家换边，不改变词条对话的位置。
- 贪吃蛇恢复经典与闯关玩法；默认关闭“吃到食物停一帧”。开启后模拟和插值停一个前台渲染帧，不等于停一个移动格步，也不触发暂停倒数。
- 连连看支持多选水果 12、食物 12、动物 12、自然 6、物件 6 种图案。所选类别只影响新开局；已开始的对局保留图案映射。关卡需要的图案多于所选数量时，会提示增加类别，不偷偷补入其他类别。
- 仅数独、扫雷、推箱子、五子棋、2048、合成大西瓜、俄罗斯方块、贪吃蛇和 Dino 接入本轮结算展示：终局先展示约 0.8 秒，再打开结果；可查看最后局面，并通过“查看结算”重新打开。查看期间不继续游戏或重复记分。回看入口由各页面预留顶栏区域，五子棋复用原有“查看结果”按钮，不占用底部说明或操作区。其余游戏保持原有结算流程与既有回看入口，不新增延迟、回看按钮或页面。

## 黄金矿工

原生玩法的新挑战使用经典面额：小/中/大金块 50/100/500，大小石头 11/20，钻石 600，地鼠 2，带钻地鼠 602。保留 60 秒、物理速度、重量、地图几何和福袋随机规则。

每关商店出售三类物品，价格随已完成关卡递增。炸药从 80 起每关加 15，力量 180/+30，幸运草 60/+10，石头书 40/+5，钻石油 220/+40。炸药单人库存 1、合作共享库存 2，其他物品库存 1；未上架与买完分别显示。关卡目标按新面额调整，并使用真实规则模拟验证地图见证。

旧挑战通过独立 balanceProfile 保留旧矿值、目标、货架、价格及已购物品，直到该挑战结束；新挑战才使用新参数。

## 平台行为

王国保卫战使用独立 Android Activity。原运行库的 OpenAL 音频暂停只识别窗口最小化事件，而 SDL3 Android 发出应用前后台事件。本轮在该运行库的 Lua/JNI 桥接管真实 OpenAL 设备的暂停/恢复，随 Lua runtime 注册与释放，不改 Unity 公共声音开关。

Unity 主窗口开启全屏和安全区外渲染；背景铺满画布，内容通过 SafeDesignFrame 避让刘海/手势区域。控件避让是有意设计，整行黑色留白并非这一设置要求。独立 Android 原版容器有各自的窗口策略。
