## 公共导航和页面切换

大厅的三种布局共用一份[游戏目录](../Assets/Scripts/Runtime/Lobby/AppController.Lobby.cs)。在这里维护游戏顺序、稳定 ID、卡片样式和进入回调。新增入口时要用同一 ID 检查双列、目录和单列，并实际从卡片进入游戏和返回。普通页面的大厅、2048 棋盘显隐和活动页面标识由[宿主导航](../Assets/Scripts/Runtime/App/AppController.Navigation.cs)同步更新。

普通顶栏使用 [UiFactory](../Assets/Scripts/Runtime/UiFactory.cs) 提供的返回、说明和设置按钮。左侧图标由回到大厅或上一级的实际动作决定。飞花令开局与对局有不同的返回目标，成语从设置进入规则后需要回到设置。横屏、独立画布和四个网页容器各自处理暂停、方向和退出确认。共用按钮的触控范围可以单独验收，数独翻页仍可点原有矩形范围的角落。

| 导航范围 | 游戏与保留的行为 |
| --- | --- |
| 普通页面控件（17 个入口） | 数独、扫雷、五子棋、军棋、象棋、国际象棋、跳棋、2048、合成大西瓜、抓大鹅、旸了个旸、跳一跳、Dino、贪吃蛇、欢乐球球、成语接龙、飞花令。各游戏继续决定按钮可见时机与返回目标。 |

| 共用位置，各游戏管理触控（4 个入口） | 推箱子保留动态点击范围，连连看保留窄屏布局和棋盘遮罩，俄罗斯方块保留按压与方向盘，Flappy Bird 保留导航触点与拍翼输入的隔离。 |

前后台事件由[宿主生命周期](../Assets/Scripts/Runtime/App/AppController.Lifecycle.cs)分发。页面共用同一份前台状态，系统暂停与中文输入法短时抢焦分别处理。网页宿主晚到的返回回调仍需检查其他宿主是否占用大厅。

## 操作反馈和存档

在原始主线上，2048 每次有效滑动都会先调用最多 19 个页面的保存方法，再播放反馈。在真实宿主上，用独立临时存档执行一次合并，能复现跳一跳的主档或备份被重写。现在 2048 滑动、重开与共用声音和触感偏好调用宿主自己的存档路径；实际退出与系统生命周期保留跨页保存。可以用同一用例核对写盘失败后的重试、设置窗口和最高纪录。

Android 和 iOS 的系统触感调用集中在[平台触感入口](../Assets/Scripts/Runtime/Platform/PlatformHaptics.cs)。Dino 仍在撞击时触发，2048 仍在合并时触发。包内资源审计对基线下 653 个已跟踪的 `Assets/Resources` 非 meta 文件做了逐字节比较。仅两对完全相同，合计 3,722 字节。资源复用优先集中到控件生成与平台调用，保留游戏美术原件、许可和 Unity GUID。
