# 连连看 48 / 96 / 192 张密度对照

`index.html` 是纯浏览器设计对照，**演示进度，不保存**。三个 iframe 直接引用[连连看原型](../link-match/README.md)，没有真实规则引擎、倒计时、活动局或生产存档读写，也不是 Unity 截图或设备交互验证。

另有 [Unity 实际截图对照](unity.html)，以相同尺度直接展示三张原始生产 UGUI PNG；48 张采用首版固定排列、轻松用时 00:32，96／192 张为扩关后挑战模式、已用时 32 秒（剩余 04:28／09:28）。它用于密度比较，不是同模式计时状态对照，也不代表真机安装或触摸验收已通过。

在仓库根目录启动本地静态服务后打开本目录的 `index.html`。例如运行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问[密度对照](http://127.0.0.1:8765/docs/prototypes/link-match-density/)。所有图片与字体均来自仓库，无 CDN 或图片网络请求。

| 样例 | 网格 | 张数 | 图案种数 | 每种数量 | 同尺寸基准下的格边长 |
| --- | --- | --- | --- | --- | --- |
| 第 03 关 | 6×8 | 48 | 12 | 4 | 约 51.33 CSS px |
| 第 04 关 | 8×12 | 96 | 24 | 4 | 35.50 CSS px |
| 第 05 关 | 12×16 | 192 | 48 | 4 | 约 25.67 CSS px |

三者都先按 **360×640 CSS px** 的安全内容尺寸渲染，采用同一轻松模式与无续局夹具；不包含假系统状态栏或手机边框。外层只应用一个共同的展示缩放因子，让三屏在桌面窗口中并排显示；没有把不同棋盘单独放大到同样格子尺寸。窄浏览器可使整体对照变小，不证明实际手指点击舒适性。

第 05 关的行列数都是第 03 关两倍，所以同可用区内格边长减半、面积为四分之一。原型与生产 `LinkMatchLayout.DecorationScale` 一致，以同尺寸第 03 关 cell 为基准缩放新两关的内缩、圆角、阴影与连线粗细，选中描边最低为 1.5 CSS px；独立整格点击区域保持互不重叠。原 01–03 关装饰保持原值。外圈仍预留 12 px 通道，示例线路距棋盘左边 8 px。

每关展示两份固定排列之一，保证每图四张及示例连线路径合法；不宣称整盘可解。时间与道具不递进；任何续局、完成、暂停、重开及保存错误仅属于演示状态。真实扩关、存档迁移及各层验收记录见[扩关验证记录](../../verification-link-match-expanded.md)；首版三关历史结果保留在[原验证记录](../../verification-link-match.md)。

[manifest.json](manifest.json) 按稳定 ID 顺序记录 48 张官方 Microsoft Fluent Emoji 3D PNG，固定上游 commit 为 `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`。原 12 张通过 `../link-match/assets/` 引用，新 36 张位于本目录 `assets/`；共 1,699,094 源文件字节，均为原始 256×256 RGBA 图片，没有裁切、重编码或改色。原型复用这些文件，未另外复制一套。

完整原始 [MIT 许可](../link-match/assets/LICENSE.fluentui-emoji.txt) 保持不变。密度 manifest 是设计来源记录；生产导入位置和元数据见[生产素材清单](../../../Assets/Resources/LinkMatch/manifest.json)，不要把两种路径混用。
