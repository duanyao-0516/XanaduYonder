# Fluent 3D fruit assets

These 12 original Microsoft Fluent Emoji PNG files are used by the link-match browser design prototype only. They are not production Unity resources.

- Official repository: [microsoft/fluentui-emoji](https://github.com/microsoft/fluentui-emoji).
- Pinned revision: [`1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`](https://github.com/microsoft/fluentui-emoji/tree/1ffb34c752ecf5d402f04cfb4b392c77f57c54bc), resolved from official `refs/heads/main`.
- License: MIT. Copyright (c) Microsoft Corporation. The complete unmodified notice is in [LICENSE.fluentui-emoji.txt](LICENSE.fluentui-emoji.txt). Retain the copyright and license notice when distributing the assets.
- Files: 12 PNGs, each 256 x 256, totaling 375,824 bytes. No cropping, resizing, recoloring, or re-encoding has been applied.
- [manifest.json](manifest.json) records each pinned source URL and path, SHA-256, byte count, dimensions, and license. The license file also has provenance and a SHA-256.

Download validation checks the PNG signature, chunk boundaries, every chunk CRC, IHDR dimensions, and IEND. The local files were re-read and checked against their recorded SHA-256 values. The prototype loads these local files without a remote CDN.
