- 水果、表情、校徽三主题，每主题 11 个等级；切换仅更新视图，校徽使用圆形遮罩。
- 独立严格版本存档 `watermelon-v1.json`，包含完整位置/速度/角度/接触历史/年龄、RNG/队列和计时；原子写入与有效备份恢复。
- 素材来自用户授权的 [idootop/watermelon](https://github.com/idootop/watermelon)，固定版本和 37 文件的 SHA-256 见[素材清单](watermelon-assets.md)。所有 C# 实现原创，未复制其 Dart 源码。

## Android 交互验证

独立包名 `com.duanyao.xanaduyonder.watermelontest`，显示名称「Xanadu 西瓜测试」。没有覆盖正式应用或其他工作树测试包。Android 16 的 OPPO PKM110（1080×2373）与本分支独立 Android API 36 ARM64 模拟器（1080×2400）均实际安装运行。

- 大厅 06 卡片完整显示，01–04 保留，固定高度列表可滚动。
- 真机连续投放产生合并、得分及持久化；三主题逐一显示，无图片拉伸、校徽白色方角或图鉴文字截断。
- 暂停中切换主题，逐字段比较保存的整个 game 对象完全不变；分数、球身份、队列和 RNG 均保留。
- 设置弹窗打开前保存，停留期间状态不推进；Android 原生 `ACTION_CANCEL` 不产生投球。
- 胜利固定局面通过真实碰撞合成 11 级并显示提示；Android 返回键回大厅且保留胜利局面；继续挑战后可继续投放。
- 真机切后台后保存文件稳定；模拟器终止进程再启动后验证保存的队列、得分、身份、主题及实际恢复的物理运动。
- 固定越线局面通过 2 秒宽限进入失败状态并存档；重开清空棋盘和本局分数，保留最高分与主题。
- 模拟器改为 720×1280 后，导航、三主题、棋盘、操作区和底部提示完整显示；随后恢复原分辨率。
- 返回 2048 实际滑动并保存，2048 对局发生变化，同时大西瓜快照保持不变。模拟器全程 Unity/AndroidRuntime 日志未发现托管异常或致命错误。
- 最终包复现临时文件写入失败：旧主存档字节不变，界面显示中文未保存提示；解除故障后成功保存当前局面并显示“进度已保存”。真机覆盖更新独立测试包后仍保留进度。

固定胜负局面只写入本分支模拟器的独立测试包，不写正式包或真机玩家存档。检查同时保留截图、物理报告和构建日志于忽略的 `artifacts/validation/` 与 `artifacts/logs/`。
