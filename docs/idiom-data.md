# 成语数据：确定性脚本清洗

本页说明成语接龙采用的数据清洗与资源导出流程。处理两个固定版本的完整成语库，输出全量统一资料、可玩子集和审计记录；游戏页面已接入该子集，不调用大模型，不生成或改写释义、典故、拼音。

## 运行

需要 Python 3.9+，仅使用标准库，不需要 pip 包。仓库现有字体参与字符覆盖检查。

```bash
scripts/test-idiom-data.sh
python3 -B scripts/import-idioms.py
```

默认从 `artifacts/idiom-research/` 读取六个源 JSON 和两个许可文件，SHA256、原始记录数与字体摘要全部匹配才开始整理。来源未缓存时运行：

```bash
python3 -B scripts/import-idioms.py --fetch
```

`--fetch` 只下载清单里固定 commit 的缺失文件；已有文件摘要不符会失败，不能用重新下载静默覆盖它。清单为 `Data/Idioms/source-manifest.json`，已发现但未能确定正确值的问题词在 `Data/Idioms/exclusions.json`；这些只有隔离原因，没有猜测修正值。

默认输出到 `artifacts/idiom-cleaned/`。相同输入、相同规则再次运行，会逐文件验证一致后复用结果。来源或脚本更新后请使用新的输出目录；已有不一致结果不会被覆盖：

```bash
python3 -B scripts/import-idioms.py --output artifacts/idiom-cleaned-next
```

## 产物

| 文件 | 内容 |
| --- | --- |
| `catalog.jsonl` | 一行一个统一词条，包含保留的义项/来源候选、出处、典故、例句、来源和质量状态 |
| `game-index.json` | 自动检查通过的四字候选；含读音、首尾字/音、详情位置和首字/首音索引 |
| `details/*.json` | 每片至多 256 个候选词的详情，后续可按需加载 |
| `review-required.jsonl` | 不进入游戏的资料和原因，包括非四字词及未解决的冲突 |
| `invalid-records.jsonl` | 无法得到合法词条正文/源结构的记录引用与原因 |
| `audit.json` | 源/规则/字体/隔离配置的摘要、统计和来源入口 |
| `report.md` | 本轮统计与结果边界 |
| `checksums.json` | 其余所有文件的 SHA256 |
| `licenses/` | 两份原始 MIT 许可文本 |

清洗生成物位于忽略目录，不将原始大文件或中间结果提交。移动端使用另行导出的压缩资源：

```bash
python3 scripts/pack-idioms.py
scripts/test-idiom-resources.sh
```

导出器先核对清洗文件 SHA256，再将唯一词条投影为运行目录与 168 个详情分片，写入 `Assets/Resources/Idioms`。每个详情分片最多 256 条，保留准确的义项 ID、原拼音、词义/典故/出处/例句和来源名称；完整来源行号仍留在清洗产物内。固定 gzip 时间戳保证同样输入的可复现导出，`manifest.json` 记录每个资源摘要。两份 MIT 许可同时打包。

当前词库版本 `d3a64eb110d46b49c1669d53`，42,851 条，全部资源合计 11,687,267 字节（约 11.7 MB）。431 词的编辑推荐表位于 `Data/Idioms/common-idioms.txt`，只影响回复和提示排序，不能解释为语料频率；不在清洗候选中的词不能进入推荐表。

运行时首次进入成语接龙异步打开索引，分帧建立目录；离开后保留索引供续玩。详情按点击加载，缓存最多四片，离开页面清掉详情缓存。异常分片不会缓存为成功，游戏使用已有中文字体，外部文字关闭富文本解析。

## 去重和数据规则

同库内部重复与跨库重复使用同一归并流程。正文采用 NFC 并去除首尾空白，以规范正文确定稳定哈希 ID；不靠数组下标，不自动改字、简繁转换或模糊合词。每条源记录以 `source/file/row/sourceId` 保留去向，重复来源不能被字典覆盖。

同名且读音、释义等价的记录合并，相同内容只保留一份，缺失内容可以互补。展示保留标点，去标点只用于比较；原文仍可从固定源文件追溯。不同读音或实质不同的释义保持分离的候选义项，`gameSenseId` 为空，不同时当作合法接音。语法检查不能把这些候选义项认定为已经核实的多义词。

产品字段包括成语、带调拼音、释义（词义/典故/出处）和可选例句。`source/derivation` 归出处，`story` 归典故，`quote/example` 归例句。没有故事就保持缺失，不把书目引用标成完整典故。近反义词、缩写、语法用法不进入生成的产品字段，但原始缓存不删除。

明确占位“无/暂无/不详”等按缺失处理。核心内容冲突、异常字段类型、拼音异常、字体缺字、非四字词或显式隔离词均不进入游戏子集。隔离原因可以重叠，不能把各原因数量直接相加当作词数。

拼音按四个标准音节和调号位置检查，保留声调用于展示，比较键去声调并保留 `ü/u` 区别，不混淆平翘舌或前后鼻音。整条完全没有调号的记录单独标记 `missing_pinyin_tones` 并隔离，个别音节无调号允许正常轻声。完整语境读音来自源词条，脚本不通过单字读音猜测。

## 验证与限制

测试覆盖同库及跨库重复、来源守恒、缺项与占位、读音/释义冲突、典故字段和顺序、字体 cmap、文件 SHA 与条数、重复生成一致、已有结果保护。全量导出另做来源守恒、唯一词条/义项与索引引用校验。

字体检查读取仓库字体的 Unicode cmap 格式 4/12，确认词条正文及显示拼音有非零字形映射；不等于所有释义字符或 Unity 渲染均已验收。通过自动检查的词称“游戏候选”，不宣称已逐条人工考据。

隔离清单中的非四字记录只是超出首版玩法，不代表资料错误。关键冲突保留原文，后续有可信依据才修订。原始资料保持不变。
