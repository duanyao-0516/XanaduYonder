# 成语数据：多来源原文保留与确定性导出

本页描述 2026-10-30 的当前数据契约，替代此前“冲突词整词隔离、选择单一游戏义项”的政策。处理两个固定版本的完整成语库，不裁定来源释义孰对孰错，不选择权威主释义，不生成、改写或猜补释义、典故和拼音。各来源原文分别展示。

旧政策的 42,851 个可玩词是历史基线；此次恢复其余 2,925 个四汉字词。释义差异、读音差异、缺字段、字体诊断和旧排除表均不再删词。其中45,674词具备可解析读音，102词仅同字可用；这些数量不表示已逐条人工考据，同音只使用源记录中可机械解析的读音。

当前目录版本为 `95ef1ff594899efa1f03ac19`；导出统计与摘要以本机新生成的 `artifacts/idiom-cleaned-preserved/report.md`、`audit.json` 和随包 [`manifest.json`](../Assets/Resources/Idioms/manifest.json) 为准。旧[验收记录](verification-idiom.md)中的测试数量和设备结果属于旧词库，不能作为此次重导出的验收证据。

## 运行与复现

需要 Python 3.9+，仅使用标准库。默认从 `artifacts/idiom-research/` 读取六个源 JSON 和两个许可文件，SHA256、原始记录数与字体摘要全部匹配才开始整理。来源清单为 [`source-manifest.json`](../Data/Idioms/source-manifest.json)。

```bash
scripts/test-idiom-data.sh
python3 -B scripts/import-idioms.py --output artifacts/idiom-cleaned-preserved
python3 -B scripts/pack-idioms.py --input artifacts/idiom-cleaned-preserved
scripts/test-idiom-resources.sh
```

缺少源文件时可加 `--fetch`，只下载清单固定 commit 的缺失文件；已有文件摘要不符会失败，不会静默覆盖。默认输出目录仍为 `artifacts/idiom-cleaned/`；本次显式使用新目录，避免复用旧规则产物。相同输入、规则与目录重跑会逐文件验证一致；不一致的已有结果不会被覆盖，后续规则变化应另设输出目录。

## 产物与移动目录

| 文件 | 内容 |
| --- | --- |
| `catalog.jsonl` | 全量统一词条、每条源记录的 `sourceVariants`、可解析的 `gameReadings`、审计义项与质量原因 |
| `game-index.json` | 全部四汉字词条；正文、展示原拼音、成对读音、详情位置和首字/首音索引 |
| `details/*.json` | 每片最多 256 个四汉字词条，各来源资料独立保存 |
| `review-required.jsonl` | 带审计原因的词条；可与游戏词库重叠，不是禁用清单 |
| `invalid-records.jsonl` | 无法取得合法词条正文/源记录外层结构的记录引用与原因 |
| `audit.json` / `report.md` | 来源、规则、字体、旧排除配置摘要，数量与处理边界 |
| `checksums.json` | 其余所有生成文件的 SHA256 |
| `licenses/` | 两份原始 MIT 许可文本 |

清洗产物位于忽略目录，移动端资源位于 `Assets/Resources/Idioms`。导出器校验清洗 SHA256，再输出 45,776 条目录与 179 个详情分片（每片最多 256 条）；gzip 时间戳固定，资源摘要写入 manifest。来源显示名称为“景墨词库”“新华成语词库”，原始 MIT 许可和作者署名保持不变。

压缩目录每行有 9 列：`[id, word, pinyinDisplay, firstKey, lastKey, definitionId, chunk, common, [[first,last],...]]`。第九列保留每个可解析读音的首尾配对，不能任意组合成新读音。第 4、5 列只兼容旧单键接口，取第一对或空串，不决定完整的同音索引。没有读音时第九列为 `[]`，同字仍可使用，同音提交明确提示该词没有可用读音。

1,534 词的编辑常用表位于 [`common-idioms.txt`](../Data/Idioms/common-idioms.txt)，是推荐优先范围，不是词频排名。导出时仍要求正文精确命中四汉字目录；未列为常用的合法词始终可以参加5%探索分支，优先范围为空时使用全部其他合法词。

运行时异步打开索引并分帧建立目录；离开页面后保留索引供续玩。详情按点击加载，缓存最多四片，离开页面清掉详情缓存。异常分片不缓存为成功；外部文字关闭富文本解析。

## 原文、读音和审计各自的职责

正文采用 NFC 并去除首尾空白，以规范正文确定稳定哈希 ID，不自动改字、简繁转换或模糊合词。同库及跨库同名记录归到一个词 ID，但每条源记录都有独立 `sourceRecordId` 和来源位置，重复源记录也不得覆盖丢失。

`sourceVariants` 保存每条来源的原拼音、词义、典故、出处和例句。`source/derivation` 归出处，`story` 归典故，`quote/example` 归例句；保持来源与原文绑定，不补写故事、不跨来源拼成标准解释，也不将占位字面值当作裁定另一来源的依据。源字段缺失可以保留为空；原始字段类型异常继续记入审计。近反义词、缩写、语法标签仍留在原始快照，本次不新增展示字段。

旧 `senses` 和 `quality.reasons` 继续用于差异诊断，不再作为展示答案或四字准入门槛。`gameSenseId`/移动详情 `SenseId` 是内容身份：单义沿用稳定 ID，多来源资料集合使用稳定集合 ID，不代表选定了主释义。[旧排除表](../Data/Idioms/exclusions.json)中的原因继续可查，但不禁用四汉字词。

`gameReadings` 仅解析来源拼音中的四个标准音节和合法调号位置；允许原文无调，但不补调、不猜缺字、不由单字词典推断。匹配键去声调并保留 `ü/u`、平翘舌和前后鼻音区别；展示保留各来源原文。无法解析的原拼音仍在资料中展示，只是不生成同音边。对局每回合仅从与上一步尾音匹配的首音对释放尾音；提示、APP 回复和历史恢复采用同一配对状态。

详情新增 `Sources`，各项包括 `SourceKey, SourceLabel, SourceRecordId, Pinyin, Meaning, Stories, Origins, Examples`。根 `Meaning` 带来源标记汇总所有词义，根典故和引用数组留空，完整展示逐来源读取 `Sources`。生词本加入时保存带来源、原拼音、词义、典故、出处和例句的完整文本快照，不只截取摘要；长度或文件上限超出时明确报错并回滚，不能静默丢来源。

## 验证边界与版本保护

测试应覆盖来源守恒、同库/跨库重复、冲突仍保留四字词、无解析读音同字可用、成对读音不能交叉组合、每条详情来源完整、唯一身份、资源引用和重复生成一致。字体 cmap 诊断继续记录，但不作为删词条件；字体映射、源码测试和 Unity/设备实际显示必须分别验证。

重新导出会改变目录版本。沿用现有存档版本保护，不自动迁移旧目录对局，不清空旧档，不绕过校验；保护原文件并走已有归档重建流程。当前验证只按实际执行结果记录，不复用旧报告中的通过结论。

普通/复习优先与全合法词探索见[选词设计](idiom-selection.md)，公共常用表及覆盖统计口径见[常用词审计](idiom-common-vocabulary.md)。
