# Dino 玩法与接入

Dino 是当前源码新增的第七款离线游戏，稳定标识为 `dino`。玩家先选择横屏或竖屏，再以跳跃、下蹲避开仙人掌和翼龙。两种方向共用同一套固定步规则、碰撞与距离计分；方向只影响布局、实际可见路程和由视野推导的安全速度上限。横／竖屏最高纪录分开保存。

本页说明玩法与模块契约，不宣告真机手感、性能或设备验收通过。设计依据见[设计稿](superpowers/specs/2026-10-27-chrome-dino-design.md)，资源出处见[素材记录](dino-assets.md)。

## 进入、暂停与离开

| 阶段 | 行为 |
| --- | --- |
| 从大厅进入 | 始终先在竖屏展示方向选择页，首次预选竖屏，之后预选上次成功进入的方向。选择选项只改变预览，确认后才请求方向。 |
| 切换方向 | 停止模拟和输入，等待实际方向、安全区和布局连续稳定两帧；超时三秒展示可重试的错误，不按错误方向开始。 |
| 准备 | 显示「按下跳跃开始」，第一次有效跳跃同时开始对局并起跳。 |
| 奔跑 | 方向保持锁定，模型按固定 60 Hz 推进，运行中的手机转动不切换模式。 |
| 暂停 | 手动暂停、帮助、设置、失焦和后台都冻结对局；返回前台不自动开跑。 |
| 继续 | 三秒倒数结束后恢复；倒数期间不移动、不出怪、不计分，后台时间不补算。 |
| 窗口变化 | 先暂停，恢复前必须满足本局视野和既有动作安全约束；无法满足时恢复原窗口或结束重开。 |
| 结束与重开 | 碰撞结束本局；「再来一局」保留本局方向回准备页，「更换方向」回选择页。 |
| 返回 | 游戏页左上角及系统返回先回方向选择；进行中的对局先确认结束并保存纪录。选择页再次返回才进入大厅。结算／异常窗口内明确标注「返回大厅」的入口直接去大厅。 |

两种方向均使用留有左右页边距的圆角跑道卡片。竖屏跑道为 656×320 设计单位；横屏在安全区两侧各留 32 单位，与跳一跳场景区一致，标题和导航沿用 56 单位文本边距。短边采用相同的角色尺寸基准，横屏新增卡片宽度用于前方视野。选择页下移方向卡及开始按钮，卡内含屏幕方向示意、独立纪录标签与加粗数值。游戏分数取消底卡，当前分数突出、最高纪录次级显示；竖屏小下蹲／大跳跃及下方暂停，横屏下蹲／暂停／跳跃，均靠近下方操作区，操作提示放在按钮内部。矮选择窗口使用保留开始按钮的卡片滚动区；竖屏游戏需要至少 1120 设计单位高度，过矮窗口提示调整方向／尺寸，避免分数、跑道及操作区相互遮挡。页面不单列更换方向按钮，从暂停菜单进入。字体、图标和配色继续使用公共 UI；声音与触感由公共 shell 持有。

## 操作与输入归属

| 输入 | 规则 |
| --- | --- |
| 右侧跳跃按钮或跑道按下 | 落地且没有真实按住下蹲时起跳；按下生效，不等待松手。 |
| 跳跃松开 | 达到最小跳高后截断上升，形成短跳；持续按住形成长跳，落地不自动连跳。 |
| 左侧下蹲按住／松开 | 地面蹲跑；空中按住加速下落，仍按住时落地保持蹲姿。 |
| 编辑器键盘 | 空格／↑ 跳跃，↓ 下蹲；Esc 进入当前页面的返回流程。 |

Jump 和 Duck 各自只有一个 owner。跳跃按钮、跑道、空格和 ↑ 共享 Jump 所有权，其他入口不抢占、不排队；只有 owner 的松开、滑出或取消可以释放该动作。空中点击不缓存为落地后的下一跳，跳跃手指松开也不会释放另一根手指的下蹲。

生命周期暂停先冻结当前动作意图，再清理真实 pointer／键盘 owner。长跳恢复后保留既定轨迹；继承的蹲姿可由新的跳跃解除并起跳，或重新按住再松开下蹲解除。恢复倒数不接受跳跃，允许下蹲输入覆盖继承姿态；旧手指不重新注册为 owner。

## 共享规则与视野约束

`Core/Dino` 不依赖 Unity。`DinoGame` 拥有角色、障碍、随机状态、行程和终局；`DinoRules` 持有尺寸、运动与反应参数；`DinoTraversal` 使用实际运动和碰撞求可通过的输入区间；`DinoCollision` 检查贴合像素实体的多矩形。

模型每步为 1/60 秒，运动和碰撞分为四个子步并使用扫掠检查。页面只累计前台运行时间；单帧超过 100 ms 时暂停，不突然追赶积压时间。碰撞后停止计分和后续里程碑反馈。

开局将跑道宽度映射为逻辑视野，竖屏卡片 656 单位宽对应约 546.67 逻辑单位，横屏按留边后的卡片实际宽度展开。当前名义速度从 180 单位／秒，以每秒增加 12 的节奏在 15 秒内达到 360；实际速度取名义值与本局安全上限的较小值。竖屏上述视野的安全上限为 267.25，在第 437 个固定步（约 7.28 秒）达到。上限在开局由视野和允许的障碍候选推导，不在危险障碍逼近时临时减速，也不对横屏使用额外的专属加速曲线。

反应窗口从障碍完整露出开始，结束于玩家最晚仍可安全执行跳跃或下蹲的时刻，不能直接用「出现到碰撞」替代。初始规则要求扣除 100 ms 输入／显示预算后仍至少 1.2 秒。求解器检查障碍完整宽度和真实轨迹，跳跃候选还要求连续可成功的按下区间；无解的组合不进入场景。前一动作完成后另保留至少 0.25 秒恢复间隔，下一障碍仍须独立满足可见反应窗口。这些是算法约束与初始调参目标，真人操作感受需要按两个方向分别验证。

| 运行时间 | 开放内容 |
| --- | --- |
| 0–3 秒 | 无危险障碍，正常计分。 |
| 3–20 秒 | 单株小仙人掌。 |
| 20–45 秒 | 加入大小仙人掌，最多三株的候选组合须通过轨迹检查。 |
| 45 秒后 | 加入低空和中空翼龙；低空跳过，中空下蹲。 |
| 15 秒后 | 名义加速结束，实际速度可能因视野约束更早达到上限。 |

分数为累计逻辑行程除以 30 后向下取整，使用非负 64 位整数并饱和保护；两方向公式相同，纪录不混排。每 100 分有里程提示。跑道白天纯白、夜晚纯黑；按实际奔跑时间每 30 秒交替昼夜，以 0.8 秒渐变过渡，暂停、倒数和结束冻结，重开回白天。昼夜和精灵动画只改变显示，不改变模型的运动、障碍或碰撞。地平线使用原图集中完整的平坦／小丘两种地形，以绝对世界分片编号稳定交替；其主体横线位于脚底上方，形成原版的脚部交叠效果，小丘不参与碰撞。加速参数与 Chromium 的区别及源码依据见[加速调研](dino-chromium-reference.md)。

## 节日与生日彩蛋

进入 Dino 时按设备本地日期离线判定，帽子类型保持到下一次从大厅进入，窗口重排和重开不会使同次进入的装饰跳变。普通日期不戴帽。节庆红金礼帽、万圣紫帽、圣诞红帽和生日派对帽都是代码绘制的像素几何，跟随角色站立、跑动、跳跃、下蹲及结束姿态，不参与碰撞。

| 日期 | 彩蛋 |
| --- | --- |
| 公历 1/1、5/1、10/1–7 | 节庆礼帽 |
| 农历正月初一至初七、五月初五、八月十五 | 节庆礼帽 |
| 公历 10/31、12/25 | 万圣帽、圣诞帽 |
| 农历四月十五、五月十六 | 生日帽；进入方向选择页显示「生日快乐」小横幅 |

这些是固定庆祝日期，不是逐年法定调休假期表。农历规则不在闰月重复触发；生日优先于普通节日。`ChineseLunisolarCalendar` 支持范围外仅计算公历节日。无联网、手机时间写入或额外存档字段。

按住跳跃沿用 Chromium 的操作方向：按下立即起跳，松开调用 `endJump` 截断上升，存在最小／最大高度约束；本项目运动参数独立调校，不宣称完全复刻原版手感。参考 [Trex 跳跃实现](https://chromium.googlesource.com/chromium/src/+/main/components/neterror/resources/dino_game/trex.ts)及[松开输入处理](https://chromium.googlesource.com/chromium/src/+/main/components/neterror/resources/dino_game/offline.ts)。

## 独立存档

最高纪录自动保存，本局退出后重新开始。同进程切后台时对局留在内存中，可以暂停续玩；主动离开或进程重启后不提供上一局恢复。

文件位于 `Application.persistentDataPath/dino-v1.json`，只包含：

```json
{
  "schemaVersion": 1,
  "gameId": "dino",
  "bestPortraitScore": "0",
  "bestLandscapeScore": "0",
  "preferredOrientation": "portrait"
}
```

- 两项纪录必须是非负 64 位整数的十进制字符串；方向仅允许 `portrait` 或 `landscape`。
- 方向偏好只在成功进入准备页后提交；预览、取消和方向切换失败不覆盖上次偏好。
- 缺字段、显式 null、错误 token、负数、溢出、重复键、额外字段及未知版本均拒绝；文件上限 4 KiB，JSON 深度上限 4。
- 主档不可用时读取合法 `.bak`；均不可用时使用零纪录和竖屏偏好，损坏或读取失败会提示。首版不迁移其他草案协议。
- 保存先写 `.tmp` 并 flush，再原子替换；只有合法主档才更新备份，损坏主档不覆盖最后一份合法备份。
- 产生新纪录时每秒最多写一次；碰撞、暂停、离开和退出时立即补写。未收到生命周期回调的强杀可能丢失最近约一秒的新纪录。
- 写入失败继续允许游玩，并显示「最高纪录暂未保存」；后续成功写入清除提示。

公共声音／触感开关继续保存在原公共设置中，不复制进 Dino 存档，也不修改其他游戏的 JSON 协议。

## 模块与素材

| 位置 | 职责 |
| --- | --- |
| `Assets/Scripts/Core/Dino/` | 纯 C# 固定步模型、规则、轨迹求解与碰撞。 |
| `Assets/Scripts/Runtime/Dino/DinoPage.cs` | 方向选择、页面状态、输入适配、计时与 shell 回调。 |
| `DinoViewport.cs`、`DinoPageLayout.cs`、`DinoTrackView.cs` | 独立安全区、留边圆角跑道几何与像素场景显示。 |
| `DinoActionOwners.cs`、`DinoTouchControl.cs`、`DinoRunClock.cs` | 输入所有权、触摸释放与固定步／倒数时钟。 |
| `DinoSaveData.cs`、`DinoSaveCodec.cs`、`DinoSaveStore.cs` | 双纪录、方向偏好、实际 JSON 校验与原子写入。 |
| `DinoAudio.cs` | 独立音源、短音效与触感，读取公共开关。 |
| `DinoCelebrationCalendar.cs`、`DinoCelebrationHat.cs` | 离线公历／农历庆祝日期与纯显示像素帽，独立于物理和存档。 |
| `AppController.cs` | 大厅入口和双纪录、路由、应用生命周期、屏幕方向请求及共用设置委托。 |

完整版权声明、许可条件和免责声明随资源打包为 `Dino/LICENSE.txt`。游戏内路径为「玩法说明 → 素材与许可」，两种方向都可从顶部书本图标打开玩法说明。文件映射与哈希见[素材记录](dino-assets.md)，许可说明见[第三方声明](../THIRD_PARTY_NOTICES.md#chromium-dino-runtime-and-design-reference-assets)。未复制 Chromium 游戏实现代码，游戏名称与说明不表示 Google 官方背书。

## 检查与独立构建

在当前工作树根目录运行：

```bash
scripts/test-dino.sh
scripts/test-dino-session.sh
scripts/test-dino-persistence.sh
scripts/test-dino-presentation.sh
scripts/test-dino-page.sh
scripts/test-dino-visual.sh
scripts/test-dino-ground.sh
scripts/build-dino.sh
```

四个独立 C# 入口分别覆盖生产规则／碰撞、动作 owner／时钟、真实存档读写和庆祝日期。它们不替代 Unity 的实际 UGUI 输入、方向与安全区布局、资源播放或 Android 生命周期验证。

构建脚本使用当前工作树的工程目录，生成 `artifacts/builds/XanaduYonder-0.4.0-dino-validation.apk`，日志为 `artifacts/logs/build-dino.log`。包标识为 `com.duanyao.xanaduyonder.dinotest`，构建入口临时设置测试包身份后恢复；正式版本号与正式发布包身份不因该入口改变。

不要在另一个工作树执行构建来替代本树验证，也不要将测试包安装到其他任务正在使用的设备。安装时明确指定空闲设备序列号和上述测试 APK；此包与正式应用、其他小游戏独立测试包拥有不同的应用数据。实际执行结果应分别记录源码审查、独立测试、Unity 编译、APK 构建及设备回归层次。
