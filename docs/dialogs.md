# 弹窗、设置与菜单控件

同一个入口只回答一个问题。合集采用以下三种布局，保留现有纸色、墨绿和游戏原画。按钮标题写清执行的动作。用户有可能丢失当前进度时，确认前说明受影响的数据并提供取消入口。[Apple HIG 的提醒设计](https://developer.apple.com/design/human-interface-guidelines/alerts)

| 玩家需求 | 布局与返回 |
| --- | --- |
| 确认重开、退出，或者处理一次错误 | 居中对话框，突出一个主要动作。取消或继续当前对局放在旁边。说明可滚动，操作区保持可见。 |
| 暂停后继续、挑一种展示方式、改少量偏好 | 使用紧凑操作面板。大厅的设置和展示方式使用底部面板，横屏玩法根据可用空间展示操作。展示方式点选即生效并关闭。 |
| 调整多类设置、查看长说明或资料 | 根页显示分类，下一层呈现选项或可滚动内容。系统返回和页内返回回到来源。子页携带当前草稿，原本需要保存的设置继续提供保存和取消。 |

竖屏的设置分类需要足够宽度显示中文标签及当前值，因此采用二级页。底部面板适合短操作，侧抽屉会同时挤占正文和选择区域。[Material 底部面板](https://developer.android.com/develop/ui/compose/components/bottom-sheets)

阻断操作的确认框、设置与底部面板使用中性黑蒙层，标准色为 `rgba(0, 0, 0, 0.40)`，即黑色占 40%。蒙层铺满所属画布，操作面板放在安全区内。打开子页时替换上一层蒙层。黄金矿工的位置教学用 16% 不透明度，便于看清提示所指的真实矿物。面板外点击是否可关闭由操作决定，涉及进度的确认始终提供明确的取消入口。iOS 系统提醒使用系统自带的背景变暗效果。短提示直接显示，局部的棋盘标记和游戏内状态提示保留玩法自己的视觉层次。

## 控件约定

可以对照两张运行截图查看蒙层和按钮的层次。[浅色大厅上的设置面板](screenshots/dialogs/lobby-settings.png) · [战斗画面上的暂停确认](screenshots/dialogs/web-resume.png)

- **开关**用于开或关的布尔设置。整行可点，圆点位置和轨道颜色共同表示状态，左侧文字保持稳定。应用设置沿用原有读写、写入失败处理和禁用条件。声音、触感、篮中数量显示分别有自己的开关。[Material 开关](https://developer.android.com/develop/ui/compose/components/switch)
- **互斥选项**用于方向布局、模式或主题。一组选项只有一个选中值。较长的主题名和带预览的选项使用单独选择页。
- **进入子页**的行带右箭头。普通操作采用浅色按钮，继续或确认等主要操作采用实色按钮。重开进行中的 2048 会说明清空当前棋盘的后果并显示独立的确认色。
- **输入边界**由玩法拥有。棋盘落子、射击、拍翼、方向盘、摇杆、按住蓄力、拖动物件和左右手热区继续由原来的输入组件处理。

## 维护入口

Unity 菜单使用 [DialogUi](../Assets/Scripts/Runtime/Navigation/DialogUi.cs)、[开关](../Assets/Scripts/Runtime/Navigation/DialogSwitch.cs)和[互斥选项](../Assets/Scripts/Runtime/Navigation/DialogChoices.cs)。[弹窗焦点管理](../Assets/Scripts/Runtime/Navigation/DialogFocusScope.cs)负责拦截底层按钮的键盘与手柄输入。[宿主弹窗](../Assets/Scripts/Runtime/App/AppController.Dialogs.cs)负责共用设置、提示、遮罩与返回。游戏内暂停、回看、重试和待保存的草稿由各玩法持有。网页管理界面使用[共用弹窗样式](../ThirdParty/WebGameUI/dialogs.css)，沿用原有 WebView 或 WKWebView 的暂停和存档协议。

| 入口 | 检查的实际操作 |
| --- | --- |
| 大厅、2048、多个玩法共用的声音与触感 | 点击整行切换，查看说明，系统返回，完成并回到来源。2048 写盘失败的处理与重试走原宿主路径。 |
| 军棋、象棋、国际象棋、跳棋 | 从设置进入落子与显示、声音与触感或对局管理。棋谱、复盘、教程和存档异常仍可从相应入口到达。 |
| 旸了个旸、成语接龙、飞花令、抓大鹅 | 验证设置子页的草稿、保存与取消。草稿和诗词输入法由各自页面管理。抓大鹅的数量显示、主题与共用声音分别进入对应分类。 |
| 数独、扫雷、五子棋、推箱子、数字华容道、连连看 | 验证规则、难度和重开确认，分别检查继续游戏、保存失败与查看最终棋盘等本款提供的动作。 |
| 贪吃蛇、俄罗斯方块、飞机大战、Flappy Bird、欢乐球球、合成大西瓜、跳一跳 | 检查暂停与继续、结算与回看，以及从规则返回。方向盘、旋转换边、投放和跳跃通过原输入路径验收。 |
| 黄金矿工、Dino、Zuma | 横屏管理面板、帮助及声音设置单独验收，恢复时回到原暂停层。 |
| Q 版泡泡堂、只有一道门、赵云与阿斗、割绳子 | 验证第一方宿主提供的设置、错误与退出界面。原引擎画布、随包美术及输入语义由原作负责。 |

常用后台验证为 `python3 scripts/test.py --group unity` 和 `python3 scripts/test.py --group platform`。实际触点、截图、设备与验证范围在每次验收中单独记录。

调整共用组件时，以下场景可以直接复跑。

| 回归入口 | 能发现的问题 |
| --- | --- |
| [俄罗斯方块 UI](../Assets/Editor/TetrisUiChecks.cs)，`tetris-ui` | 缩放并旋转安全区，采样画布四边蒙层前后的像素，再从同一点发射点击。验证独立子画布的边界及系统设置返回暂停页。 |
| [四棋 UI](../Assets/Editor/ClassicBoardGamesUiChecks.cs)，`classic-boards-ui` | 暂停后进入设置时只出现一层蒙层。切换显示或声音开关后，方向导航、焦点和保存失败重试都能继续。 |
| [成语 UI](../Assets/Editor/IdiomUiChecks.cs)，`idiom-ui` | 用方向键选择开关、用确认键写入。回到输入框时，确认候选词保留草稿，点发送只产生一次作答。 |
| [大厅和共用设置 UI](../Assets/Editor/MiniGameUiChecks.Results.cs)，`minigame-ui` | 从真实设置按钮打开底部面板。底层按钮拒绝确认键，二级页替换原蒙层，完成后焦点回到打开面板的按钮。 |
