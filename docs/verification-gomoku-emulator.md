## 证据与过程备注

证据位于 `artifacts/validation/gomoku-emulator/`：

- `environment.json`：目标 AVD、API、ABI、分辨率与 APK 散列。
- `events.jsonl`：65 条通过断言，包含实际棋谱。
- `final-logcat.txt`、`crash-buffer.txt`：运行日志；`final-save.json`：最终恢复棋局。
- `13-local-black-win-result.png`、`16-hard-ai-thinking.png`、`17-hard-ai-paused.png`、`23-local-white-win-result.png`：终局与 AI 在途取消证据。
- `26-save-failure-board.png` 至 `31-confirmed-recovery-new-game.png`：文件故障、恢复及确认保护。
- `32-draw-restored-board.png`、`33-draw-result.png`：和棋恢复。

首次流式安装遇到 ADB 连接中断，改用 `adb -s emulator-5590 install --no-streaming -r ...` 后成功，后续操作稳定。模拟器使用 5590 端口，启动日志提示超出推荐端口区间；实际目标发现、安装、输入与读取均成功。

坏档取消用例初次使用了本地双人设置页的按钮坐标，误点了人机设置页的确认按钮。依据截图修正为人机“取消”后，重新从双档损坏开始执行并通过；该脚本坐标错误未作为生产缺陷处理。

模拟器测试不能证明真机多指与系统触摸取消、触感、功耗、发热或所有机型适配。AI 只验证了实际应手与取消流程，没有把外部轮询等待时长当作搜索性能基准。真机验证仍按用户安排另行进行。
