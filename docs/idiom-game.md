# 成语接龙：玩法与页面说明

成语接龙是一款离线的对话式小游戏：用户与 APP 轮流说成语，随时点开释义，把想记住的词加入生词本。

**当前状态：规则、页面与离线词库已接入，验收范围见[验证记录](verification-idiom.md)。** 本文记录玩法与 UI；数据规则见[词库说明](idiom-data.md)，技术接入见[设计方案](superpowers/specs/2026-10-26-idiom-chain-design.md)。

## 一、玩法规则

| 项目 | 规则 |
| --- | --- |
| 同字接龙 | 上个成语末字等于下个成语首字，如“一心一意 → 意味深长”。 |
| 同音接龙 | 首尾音节相同即可，声调不限，如“一心一意 → 一帆风顺”。采用词库中该成语的语境读音，区分 ü/u、平翘舌和前后鼻音。 |
| 开局 | 每局选择“机器开局”或“人先开始”。人先开始的第一词只检查是否为词库收录的四字成语，不要求接字或接音。 |
| 不可重复 | 本局用户和 APP 说过的成语都不能再用；APP 回复和提示候选也必须排除这些词。看释义、看提示和加入生词本不算使用。 |
| 提示 | 免费，没有跨局总限额；本局成功展示第 3 次新提示后立即结算。同一回合重复查看已有提示不重复计次，新一局归零。 |
| 完成数量 | 只计算用户有效提交的成语，包含用户开局首词。APP 回复和未发送的提示不计数；前两次提示辅助提交的合法词正常计数。 |
| 结束 | 第 3 次提示、任一方无词可接、用户主动结束，都会进入鼓励小结，不显示“失败”。没有倒计时或错误次数限制。 |
| 保存 | 两种模式各自保存对局、草稿和最佳数量；切模式、返回大厅、打开生词本都不结束本局。生词本跨模式、跨对局共用。 |

APP 优先使用常见且能继续接下去的成语，相近候选间随机选择。错误输入只在输入框附近说明原因，不进入聊天、不计数、不扣提示次数。

## 二、整体 UI

沿用 APP 的米白背景和绿色配色。顶部导航与底部输入固定，中间对话填满剩余空间；适配状态栏、底部手势区和键盘，不把整页缩在屏幕中间。

APP 气泡在左，浅绿色；用户气泡在右，深绿色配白字。每个气泡显示大号成语和小号带调拼音，整块可点击看释义。

```text
顶部导航    ‹ 大厅    成语接龙    生词本    ⋯
模式切换          同字接龙  |  同音接龙
状态栏      请接“入”开头       本轮完成 1 个
────────────────────────────────────────
APP：一心一意
      yī xīn yī yì
                         你：意味深长
                             yì wèi shēn cháng
APP：长驱直入
      cháng qū zhí rù
             （聊天区域可上下滚动）
────────────────────────────────────────
输入区      提示 0/3   [输入四字成语……]  发送
```

“提示 0/3”中的数字表示本轮**已使用**次数。提示和小结中的“词条数”与“提示次数”分别标注，避免混淆。

## 三、各页面与弹窗

### 1. 大厅入口

新增“成语接龙”游戏卡，副标题“一来一往，认识更多好词。”，首次进入词库前显示双模式说明，载入后展示当前模式的最佳完成数量。卡片沿用现有高度和间距，新增游戏通过纵向滚动访问，不压缩卡片。

点击卡片进入上次使用的模式；有存档就续玩，没有存档就显示开局选择。

### 2. 开局选择（游戏页的初始状态）

保留顶部导航和模式切换；内容区显示“谁来开个头？”，下方两个等宽按钮：**左侧“机器开局”，右侧“人先开始”**。旁边用一行小字说明“本局不重复，第 3 次提示后回顾本轮”。

选择前不显示输入栏，不能发送或使用提示，也不自动弹键盘。选机器开局后显示 APP 首词与输入栏；选人先开始后显示输入栏并聚焦，提示“输入一个你想到的四字成语”。开局按钮随选择完成而收起，恢复已有对局时不重复出现。

### 3. 接龙中（游戏主页）

- **顶部**：返回大厅、标题、“生词本”小按钮和菜单。菜单含“玩法说明”“结束本轮”“新一局”。如果运行中存档损坏，另提供“保留旧档，保存当前进度”，先归档旧文件，再保存当前两个模式。
- **模式与状态**：切换同字/同音；显示本轮完成数量，以及下一词应接的字或读音。
- **中间**：双方交替的成语气泡。新回复在接近底部时自动跟随；用户正在看历史时保留位置，显示“新回复”入口。拖动聊天不会误开释义。
- **底部**：提示按钮、单行输入框和发送按钮。空输入时发送不可用；输入法选字、回车、失焦不自动发送。有效提交后清空输入，错误时保留原文。

键盘打开时输入栏位于键盘上方，对话区域相应缩短。APP 回复采用短动画，动画不额外锁住下一次操作。切模式会保存当前局，再恢复另一个模式，不把旧链条套用新规则。

### 4. 提示弹窗

前两次提示采用居中小弹窗，标题“本轮第 1 次提示”或“本轮第 2 次提示”，列出最多 3 个可接的成语。每行主区域显示成语和拼音，右侧提供“释义”入口。

点击成语主区域，关闭提示并填入输入框，用户仍需点击发送；点击“释义”只看资料，不填入、不再计次。提示生成失败或没有候选不消耗次数。

同一回合再次打开按钮显示为“查看提示”，内容不变、不重复计次。提交有效成语并收到 APP 回复后，下一回合才可申请新提示。第 3 次不再打开普通提示弹窗，直接进入带候选词的本轮小结。

### 5. 成语详情弹窗

弹窗居中，顶部固定显示成语、带调拼音和关闭按钮，中间正文可滚动：**词义 → 典故 → 出处 → 可选例句**。没有资料的小节不显示，不展示近反义词和语法用法。

底部主按钮为“加入生词本”，成功后变为不可重复点击的“已加入”，旁边提供“复制成语”。在生词本中查看时，另提供清楚标注的“移出生词本”操作。资料来源用底部小字展示。

点击聊天气泡、提示中的“释义”、小结候选或生词本条目，都使用这一弹窗。打开时收起键盘，关闭时保留草稿和位置，不自动重新弹键盘。一次只显示一层弹窗；从提示或小结打开详情时替换内容，关闭详情回到原提示或小结。

### 6. 本轮小结

居中显示完成数量和鼓励文案，例如：“这轮你完成了 12 个成语！把新认识的词收进生词本，下次又能多接几个。”只有实际刷新纪录才显示“新纪录”。完成 0 个时显示“这次先认识几个新成语，下轮再试试”。

第 3 次提示触发时，小结内附本次最多 3 个候选词；点击可看释义并加入生词本，不能再发送，也不计入本轮数量。APP 无词可接时可补充“这个词把我难住了”，其他结束原因采用中性说明，不写“失败/机器获胜”。

底部有“再来一局”“生词本”“回看本轮”。回看后保留全部气泡，输入区变为“本轮已完成”，附“本轮小结”和“再来一局”两个按钮，不再接受新词。“本轮小结”可重新查看最后一次提示，退出恢复后仍可打开，不重复计次。再来一局清空当前模式的本局记录和提示次数，重新选择开局方，最佳记录及生词本保留。

### 7. 生词本（二级页面）

顶部为返回箭头、标题“生词本”和已收录数量。主体是可滚动列表，按最近加入排序，每项显示成语、拼音和一行释义摘要；点击条目打开详情。

同一成语只保留一条。列表为空时显示“点开成语，加入想记住的词”。不主动把提示词或所有对话词加入，始终由用户在详情中选择。

从游戏或小结进入生词本不会结束对局、重置提示或清除草稿。返回时恢复原游戏；若从小结进入，则恢复原小结。关闭生词本中的详情只回列表，不直接回游戏或大厅。

## 四、反馈与返回规则

| 场景 | 界面反馈 |
| --- | --- |
| 输入不是四字 | “请输入一个四字成语”，保留输入。 |
| 词库未收录 | “本地词库暂未收录这个成语”，不直接断言它不是成语。 |
| 本局重复 | “这个成语本轮已经用过了，换一个试试。” |
| 首尾不匹配 | 指明“请接‘意’字开头”或“请接读音 yi，声调不限”。 |
| 保存对局失败 | 显示具体保存原因，允许继续；旧档需要恢复时引导到右上角菜单，成功保存后清除提示。 |
| 加入生词本失败 | 显示具体保存原因，不假报“已加入”；运行中坏档可先归档，再保存当前已读取的生词本。 |
| 详情加载失败 | 保留成语与拼音，显示“详情暂不可用”和重试。 |

返回键有弹窗时先关闭弹窗；没有弹窗时先收起键盘，再按“生词本 → 游戏 → 大厅”逐级返回。从提示/小结进入详情时，关闭会回到原内容。有未结束进度时，“结束本轮”和“新一局”需要确认；普通返回和切模式自动保存。

## 五、验收要点

- 两种模式 × 两种开局均可完整游玩；用户第一词与完成数量口径一致。
- 用户、APP、提示统一遵守本局去重；退出恢复不能绕过。
- 前两次新提示继续游戏，第 3 次展示即结算；重复查看不误扣，未发送候选不计数。
- 左右气泡、键盘避让、历史滚动和弹窗返回均符合上述描述；快速输入不被回复动画吞掉。
- 聊天、提示、小结和生词本的词条都可查释义；加入去重、移除、跨局保存正常。
- 长屏真机、短屏模拟器、大厅滚动和后台恢复的实际验证范围记入验证记录，不扩大为所有机型均已验证。
