# 成语接龙：玩法与页面说明

成语接龙是一款离线的对话式小游戏，支持人机对战与本地双人对战。双方轮流说成语，随时点开释义，把想记住的词加入生词本。

**版本边界：本文描述 v0.4.0 的本地双人、个人学习与 UI 行为；发行情况见[v0.4.0 发布记录](releases/v0.4.0.md)。** 本轮实施与验收范围见[调整计划](superpowers/plans/2026-10-27-idiom-local-ui.md)，已执行的历史验收见[验证记录](verification-idiom.md)。数据规则见[词库说明](idiom-data.md)，原始技术接入见[设计方案](superpowers/specs/2026-10-26-idiom-chain-design.md)。

## 一、玩法规则

| 项目 | 规则 |
| --- | --- |
| 同字接龙 | 上个成语末字等于下个成语首字，如“一心一意 → 意味深长”。 |
| 同音接龙 | 首尾音节相同即可，声调不限，如“一心一意 → 一帆风顺”。采用词库中该成语的语境读音，区分 ü/u、平翘舌和前后鼻音。 |
| 对战方式 | 可选择“人机对战”或“本地双人”。本地双人在同一设备上轮流操作，共用输入框；左方发言在左，右方发言在右。 |
| 开局 | 人机选择“机器开局”或“人先开始”；本地双人选择左方或右方先开始。用户开局首词只检查是否为词库收录的四字成语，不要求接字或接音。 |
| 不可重复 | 本局双方说过的成语都不能再用；APP 回复和提示候选也必须排除这些词。看释义、看提示和加入生词本不算使用。 |
| 提示 | 免费，没有跨局总限额。人机沿用用户本局 3 次；本地双人每人独立 3 次，任一方成功使用第 3 次新提示立即结束整局。同一回合重复查看已有提示不重复计次，新一局归零。 |
| 完成数量 | 人机只计算用户有效提交；本地双人分别统计左方和右方。包含用户开局首词；APP 回复和未发送的提示不计数，合法的提示辅助提交正常计数。 |
| 结束 | 第 3 次新提示、任一方无词可接、用户主动结束，都会进入鼓励小结，不显示“失败”。没有倒计时或错误次数限制。 |
| 保存 | 同字/同音 × 人机/本地双人，共 4 份独立对局、草稿和最佳数量；切规则、切对战方式、返回大厅、打开生词本都不结束当前局。生词本跨规则、跨对战方式、跨局共用。 |

APP 优先使用常见且能继续接下去的成语，相近候选间随机选择。错误输入只在输入框附近说明原因，不进入聊天、不计数、不扣提示次数。

## 二、整体 UI

沿用 APP 的米白背景和绿色配色。顶部导航与底部输入固定，中间对话填满剩余空间；适配状态栏、底部手势区和键盘，不把整页缩在屏幕中间。

人机中 APP 气泡在左，浅绿色；用户气泡在右，深绿色配白字。本地双人中左方沿用左侧气泡、右方沿用右侧气泡。每个气泡显示大号成语和小号带调拼音，整块可点击看释义。标题与完成数量以页面中线居中；完成数量同一行的右侧放紧凑的“字 / 音”滑动切换，不占整行。

```text
顶部导航    大厅图标       成语接龙       生词本图标  设置图标
规则与计数               本轮完成 1 个          [字 / 音]
状态栏                   请接“入”开头
────────────────────────────────────────
APP：一心一意
      yī xīn yī yì
                         你：意味深长
                             yì wèi shēn cháng
APP：长驱直入
      cháng qū zhí rù
             （聊天区域可上下滚动）
────────────────────────────────────────
输入区      提示 0/3   [输入四字成语……]  发送
```

“提示 0/3”中的数字表示本轮**已使用**次数。提示和小结中的“词条数”与“提示次数”分别标注，避免混淆。

本地双人的输入区随当前方切换：左方回合为“左侧发送、右侧提示”，右方回合为“左侧提示、右侧发送”。提示次数显示当前方的用量。大厅、生词本、设置采用统一的图标语言、尺寸与触控区域。

## 三、各页面与弹窗

### 1. 大厅入口

新增“成语接龙”游戏卡，副标题“一来一往，认识更多好词。”，首次进入词库前显示双模式说明，载入后展示当前模式的最佳完成数量。卡片沿用现有高度和间距，新增游戏通过纵向滚动访问，不压缩卡片。

点击卡片进入上次使用的规则和对战方式；有存档就续玩，没有存档就显示开局选择。

### 2. 开局选择（游戏页的初始状态）

保留顶部导航、规则切换和对战方式选择。人机显示“谁来开个头？”，下方两个等宽按钮：**左侧“机器开局”，右侧“人先开始”**。本地双人显示左方、右方开局选项，并说明双方各有 3 次提示，任一方第 3 次提示后回顾本轮。

选择前不显示输入栏，不能发送或使用提示，也不自动弹键盘。选机器开局后显示 APP 首词与输入栏；选用户开局后显示输入栏并聚焦，提示“输入一个你想到的四字成语”。开局按钮随选择完成而收起，恢复已有对局时不重复出现。

### 3. 接龙中（游戏主页）

- **顶部**：大厅图标、居中的标题、生词本图标和设置图标，下方可选择人机或本地双人。设置含“玩法说明”“结束本轮”“新一局”。如果运行中存档损坏，另提供“保留旧档，保存当前进度”，先归档旧文件，再保存当前 4 份对局。
- **规则与状态**：紧凑的字/音滑动切换；完成数量居中，本地双人显示双方合计；另显示当前方和下一词应接的字或读音。
- **中间**：双方交替的成语气泡。新回复在接近底部时自动跟随；用户正在看历史时保留位置，显示“新回复”入口。拖动聊天不会误开释义。
- **底部**：提示按钮、单行输入框和发送按钮。本地双人按当前方调整发送和提示的左右位置。空输入时发送不可用；输入法选字、回车、失焦不自动发送。有效提交后清空输入，错误时保留原文且不换方。

键盘打开时输入栏位于键盘上方，对话区域相应缩短。APP 回复采用短动画，动画不额外锁住下一次操作。本地双人每次有效提交后立即轮到另一方，不生成 APP 回复。切规则或对战方式时保存当前局，再恢复目标组合的独立进度。

### 4. 提示弹窗

前两次提示采用居中小弹窗，标题“本轮第 1 次提示”或“本轮第 2 次提示”，列出最多 3 个可接的成语。每行主区域显示成语和拼音，右侧提供“释义”入口。

点击成语主区域，关闭提示并填入输入框，用户仍需点击发送；点击“释义”只看资料，不填入、不再计次。提示生成失败或没有候选不消耗次数。

同一回合再次打开按钮显示为“查看提示”，内容不变、不重复计次。人机在用户提交并收到 APP 回复后可申请新提示；本地双人轮到下一方后使用该方自己的提示额度。任一用户的第 3 次不再打开普通提示弹窗，直接进入带候选词的本轮小结。

### 5. 成语详情弹窗

弹窗居中，顶部固定显示成语、带调拼音和关闭按钮，中间正文可滚动：**词义 → 典故 → 出处 → 可选例句**。没有资料的小节不显示，不展示近反义词和语法用法。所有弹窗使用圆形关闭按钮，X 在圆内水平、垂直居中；点击面板外的遮罩也关闭当前弹窗，面板内部点击不穿透关闭。

底部主按钮为“加入生词本”，加入后变为“我记住了”，点击会移出生词本并加入个人熟悉词，旁边提供“复制成语”。词已在生词本时另提供“移出生词本”，只移除生词标记，不新增熟悉证据。资料来源用底部小字展示，名称使用“景墨词库”；上游许可证和作者原始署名保持原文。

点击聊天气泡、提示中的“释义”、小结候选或生词本条目，都使用这一弹窗。打开时收起键盘，关闭时保留草稿和位置，不自动重新弹键盘。一次只显示一层弹窗；从提示或小结打开详情时替换内容，关闭详情回到原提示或小结。

### 6. 本轮小结

居中显示完成数量和鼓励文案，例如：“这轮你完成了 12 个成语！把新认识的词收进生词本，下次又能多接几个。”只有实际刷新纪录才显示“新纪录”。完成 0 个时显示“这次先认识几个新成语，下轮再试试”。

本地双人小结分别显示左方、右方的有效成语数，明确是哪一方的第 3 次提示结束了本局，不把两方的提示次数合成一个 3 次额度。

第 3 次提示触发时，小结内附本次最多 3 个候选词；点击可看释义并加入生词本，不能再发送，也不计入本轮数量。完整词库中 APP 无词可接时可补充“这个词把我难住了”；适合的推荐词用尽时则显示“这一轮适合的词先接到这里”，其他结束原因采用中性说明，不写“失败/机器获胜”。

底部有“再来一局”“生词本”“回看本轮”。回看后保留全部气泡，输入区变为“本轮已完成”，附“本轮小结”和“再来一局”两个按钮，不再接受新词。“本轮小结”可重新查看最后一次提示，退出恢复后仍可打开，不重复计次。再来一局只清空当前规则与对战方式的本局记录和提示次数，重新选择开局方，其余组合进度、最佳记录及生词本保留。

### 7. 生词本（二级页面）

顶部为返回箭头、标题“生词本”和已收录数量。主体是可滚动列表，按最近加入排序，每项显示成语、拼音和一行释义摘要；点击条目打开详情。

同一成语只保留一条。列表为空时显示“点开成语，加入想记住的词”。不主动把提示词或所有对话词加入，始终由用户在详情中选择。

从游戏或小结进入生词本不会结束对局、重置提示或清除草稿。返回时恢复原游戏；若从小结进入，则恢复原小结。关闭生词本中的详情只回列表，不直接回游戏或大厅。

## 四、反馈与返回规则

| 场景 | 界面反馈 |
| --- | --- |
| 输入不是四字 | “请输入一个四字成语”，保留输入。 |
| 词库未收录 | “本地词库暂未收录这个成语”，不直接断言它不是成语。 |
| 本局重复 | “这个成语本轮已经用过了，换一个试试。” |
| 首尾不匹配 | 指明“请接‘意’字开头”或“请接读音 yi，声调不限”。 |
| 保存对局失败 | 显示具体保存原因，允许继续；旧档需要恢复时引导到右上角菜单，成功保存后清除提示。 |
| 加入生词本失败 | 显示具体保存原因，不假报“已加入”；运行中坏档可先归档，再保存当前已读取的生词本。 |
| 详情加载失败 | 保留成语与拼音，显示“详情暂不可用”和重试。 |

返回键有弹窗时先关闭弹窗；没有弹窗时先收起键盘，再按“生词本 → 游戏 → 大厅”逐级返回。从提示/小结进入详情时，关闭按钮、遮罩和返回键都回到原内容。有未结束进度时，“结束本轮”和“新一局”需要确认；普通返回、切规则和切对战方式自动保存。

v0.4.0 使用新的 `idiom-learning-v1.json`，把四组对局、生词本与个人学习状态一起保存，保留严格校验、备份及坏档保护。本轮按用户要求不迁移旧协议；旧文件原样保留。正常点击“新一局”仅重置当前对局，学习状态不清空。

## 五、验收要点

- 同字/同音 × 人机/本地双人 4 个组合各自续玩；两种开局均可完整游玩，用户第一词与完成数量口径一致。
- 用户、APP、提示统一遵守本局去重；退出恢复不能绕过。
- 本地双人左右交替、错误不换方、发送/提示位置跟随当前方；每方前两次新提示继续，第 3 次立即结束整局，重复查看免费，小结分方计数。
- 4 个槽位不串档，四组对局、生词本和个人学习状态原子保存；本轮按要求不迁移旧协议存档。
- 标题和计数居中、右侧字/音滑动切换、统一导航图标、圆内居中 X 及遮罩关闭符合约定；左右气泡、键盘避让、历史滚动和弹窗返回正常。
- 聊天、提示、小结和生词本的词条都可查释义；加入去重、移除、跨局保存正常。
- 验证顺序为 Core/持久化与资源测试、实际 Unity 几何检查、长屏/短屏 Android UI、独立审查；只记录实际完成项，不把源码或几何测试替代设备验收。

## 六、个性化选词与学习

公共常用词、个人熟悉词与生词本共同参与推荐；普通与复习池均非空时，以 80% / 20% 选择池，再加权随机选择。只有人机对战中本回合未提示、未查看释义的合法输入积累个人熟悉词；双人不积累。生词自动复习间隔至少一天，查看或输入不受此限制。推荐必须存在未用的普通后继，全部输入仍按完整词库验证。公式、事件、辅助来源和存储设计见[选词与个人学习设计](idiom-selection.md)。
