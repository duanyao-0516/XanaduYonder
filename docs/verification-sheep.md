## OPPO 真机

设备：OPPO PKM110，Android 16，1080×2373。开发 APK 覆盖升级安装成功。

- 大厅三卡保持 350 设计单位高度、24 间距；介绍和列表纵向滚动，顶部导航固定，第三卡按钮可完整滚入视口。
- 大厅、标题和帮助使用「旸了个旸」。18 张教学关逐张点击完成，结算按钮进入新生成的 144 张挑战关。

- 覆盖牌露出的角落不能选取；上牌取走后下牌解锁；盲堆只显示顶牌图案和剩余数量。
- 验证移出前三张、暂存牌重新选入、撤回到准确暂存位置、工具只能用一次；洗牌保持已选牌、布局与全部图案数量不变。

- 按 Home 再恢复、结束进程后重开均保持精确卡槽、暂存、工具和 RNG 状态；设置弹窗阻止棋盘取牌。
- 人为损坏新游戏主存档后，Unity Player 从合法备份恢复并显示提示；原文件由合法数据修复。
- 测试前新备份 2048 与跳一跳。弹窗输入测试触发的触感开关已在 UI 中恢复；最终两个旧游戏的主档和备份及全局设置均与测试前 SHA-256 一致。未用历史旧备份覆盖用户近期进度。
