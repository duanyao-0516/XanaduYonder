# 公共常用成语表与覆盖审计

公共常用表 C 是 APP 回复与提示的学习范围之一。它不限制用户输入，不代表词频排名，也不意味着每位用户都认识表内所有词。个人熟悉词 F 和生词本 N 的优先关系、复习概率及权重见 [选词设计](idiom-selection.md)。

## 本次扩充

2026-10-27 将 `Data/Idioms/common-idioms.txt` 从 **431** 词扩充到 **1,534** 词，增加 **1,103** 词；原 431 词保持。新增词按数量与时间、学习与做事、品德与交往、感受与神态、自然与场景、故事与动物、生活表达等主题整理，包含“一望无际”。

候选在开发阶段按日常表达、学校学习和常见故事等主题进行编辑策划，熟悉程度属于编辑判断；没有将这次策划称为权威词频统计，也没有声称全表经过逐词语言学人工考据。编辑表只保存词条正文，不生成、改写原始拼音和释义。

本轮 1,420 次候选记录去重后为 1,401 词，其中 46 词已在原表；238 词未通过现有可玩索引门槛，另将 14 个偏生僻、倒序变体或不适合此编辑范围的候选排除。最终保留 1,103 个新增词。排除词及逐项原因在 [`common-expansion-audit.json`](../Data/Idioms/common-expansion-audit.json)，不是词条正确与否的最终定论。

词条、拼音、释义继续来自 [源清单](../Data/Idioms/source-manifest.json) 固定的景墨词库数据与新华成语词库版本；未引入新来源或许可。词表扩充仅改变 `catalog.bytes` 的 Common 标记及目录版本；详情分片、已通过的 42,851 个词条和源资料未因这次扩充改变。

## 纳入标准

1. 优先选日常交流、阅读与常见故事中可解释、可识别的四字表达；不靠罕见古字或冷僻典故增加数量。
2. 必须与当前清洗后的可玩索引**正文完全一致**，已有确定的义项与拼音；不得用简称、猜测读音、近似拼写或简繁模糊匹配补入。
3. 不把两个来源都收录等同于常用，不把全量词库自动标记为 Common。
4. 不为接龙连通性强行添加生僻后继。公共词没有普通后继时仍可供用户输入和查阅，APP 的质量规则会决定能否主动选它。
5. 候选整理阶段显式去重；最终词表再有重复时导出器必须报错，不能依赖集合静默吞掉重复。

例如“一针见血”“兴高采烈”“聚精会神”“如鱼得水”虽然熟悉，现有清洗记录均有 `meaning_conflict` 和 `unresolved_senses`，不在本次 42,851 条可玩索引中，因此没有越过质量门槛补入。要恢复这类词，应单独核对两个来源的具体义项、确定依据，再更新清洗规则或已核实的数据；本次不猜测解决。

## 静态覆盖结果

使用完整 42,851 词目录测量。此表只考虑公共常用词 C，不含个人 F、N；每个合法用户输入作为一个测试起点，只将这个输入标为已用。候选必须未用，其后继必须是不同且未用的公共常用词。

| 指标 | 同字：原 431 词 | 同字：新 1,534 词 | 同音：原 431 词 | 同音：新 1,534 词 |
| --- | ---: | ---: | ---: | ---: |
| 常用表覆盖的开头字/音键 | 135 | 555 | 100 | 257 |
| 自身存在另一常用后继的常用词 | 138 | 717 | 250 | 1,400 |
| 全量输入中至少有一个常用回复的词 | 8,499 | 16,794 | 22,621 | 38,107 |
| 全量输入中至少有一个合格回复的词 | 5,432 | 11,944 | 18,797 | 37,702 |
| 全库可接但无合格推荐回复的输入 | 33,573 | 27,061 | 24,017 | 5,112 |

“合格回复”要求 APP 回复本身在 C，且回复后还有 C 内可接词，排除当前输入与回复自身。比例分母若取全部合法输入，同字合格覆盖为 27.87%，同音为 87.98%。它们是静态覆盖上限，**不是整局完成率、随机开局成功率或用户实测概率**：后续一局中已使用的词更多，候选会继续减少；个人熟悉词可扩大范围，生词标记会改变普通池。

同字规则仍容易遇到推荐范围穷尽。例如“一望无际”现在是 Common，但以“际”开头的现有三个词均未列为公共常用词，单靠 C 不能保证继续。APP 不应为保证局长而强行输出冷僻词；应走选词设计定义的友善结算，或由用户选择同音模式体验。是否继续扩充应依据真实用户词汇与使用反馈，不以减少死路为唯一目标。

## 可复跑命令

只需仓库已有 Python 标准库。审计从打包资源读取，不需联网；基线通过 Git 只读获取，不切换分支或工作区。

```bash
# 清洗缓存已存在时，重新导出并验证资源
python3 scripts/pack-idioms.py
scripts/test-idiom-resources.sh

# 比较本轮扩充前的 431 词版本，输出完整统计
python3 scripts/audit-idiom-common.py \
  --baseline-revision b066953b37bf34328466830b43488a92c853f82f

# 只看当前版本
python3 scripts/audit-idiom-common.py
```

提交的 [`common-coverage-audit.json`](../Data/Idioms/common-coverage-audit.json) 保存词表 SHA256、基线 revision、目录版本和统计结果。测试会重新计算当前统计并比对，防止修改词表后留下过期报告。新增审计测试覆盖：自环不作为自身后继、已使用前词不得再次作为后继、字与音使用独立索引、全词库有解不等于推荐范围有解。

本次目录版本为 `f1a8938cc8af8eb4fed5fb1c`，完整资源合计 11,688,836 字节；导出器使用固定 gzip 时间戳。之后扩充常用表时，应重新打包、更新审计与版本数字，并跑资源和选词测试。
