# 公共常用成语表与覆盖审计

公共常用表 C 是 APP 回复与提示的优先范围之一。它不限制合法输入和 APP 的全库候选资格，不代表词频排名，也不意味着每位用户都认识表内所有词。个人熟悉词 F、生词本 N、95% 优先分支与 5% 探索分支见[选词设计](idiom-selection.md)。

## 常用表与历史扩充

2026-10-27 将 `Data/Idioms/common-idioms.txt` 从 **431** 词扩充到 **1,534** 词，增加 **1,103** 词；原 431 词保持。新增词按数量与时间、学习与做事、品德与交往、感受与神态、自然与场景、故事与动物、生活表达等主题整理，包含“一望无际”。本次来源原文保留更新不改动这份编辑表。

候选熟悉程度属于编辑判断，未声称这是权威词频或逐词语言学考据。编辑表只保存词条正文，不生成、改写拼音和释义。历史扩充的 1,420 次候选记录去重后为 1,401 词：46 词已在原表，238 词当时被旧可玩门槛挡住，另有 14 个编辑排除项，最终新增 1,103 词。逐项记录保留在 [`common-expansion-audit.json`](../Data/Idioms/common-expansion-audit.json)。

**上述 238 词的旧排除原因仅是历史记录。** 2026-10-30 起，全部 45,776 个四汉字词进入同字目录；“一针见血”“兴高采烈”“聚精会神”“如鱼得水”等词的 `meaning_conflict` 或 `unresolved_senses` 不再阻止接龙。它们没有被自动追加为 Common，但具备合法输入及全库选词资格。各来源释义分别展示，不需裁定一个标准答案才能恢复词条。

来源仍为[固定源清单](../Data/Idioms/source-manifest.json)中的景墨词库和新华成语词库，许可不变。新目录从 42,851 增至 45,776 词，详情同时扩展为逐来源原文；当前版本和包体以随包 [`manifest.json`](../Assets/Resources/Idioms/manifest.json) 为准，不能沿用旧目录版本和大小。

## 纳入 Common 的标准

1. 优先选日常交流、阅读与常见故事中可解释、可识别的四字表达，不靠罕见古字或冷僻典故增加数量。
2. 正文必须精确命中四汉字目录；不使用简称、近似拼写或简繁模糊匹配，不猜读音。是否有可解析读音单独决定同音资格，不裁定来源释义。
3. 不把两个来源都收录等同于常用，不把全量词库自动标为 Common。
4. 普通后继数量仅轻微影响选词权重；没有普通后继的合法词仍可被 APP 选中和提示。
5. 候选整理阶段显式去重；最终词表再有重复时导出器必须报错，不能依赖集合静默吞掉重复。

Common 之外的词也始终保留选择机会：优先池与其他合法候选均非空时采用 95% / 5% 分支；任一为空时使用另一类。生词自动复习冷却只影响优先身份，不能让一个合法词完全失去资格。“一望无际”的同字后继即使不在 Common，也可继续接龙；只有全词库没有未用合法接法才按无词可接结算。

## 当前静态覆盖口径

[`common-coverage-audit.json`](../Data/Idioms/common-coverage-audit.json) 使用 schema 2，绑定当前目录版本和词表 SHA256。审计不含个人 F、N，仅将每个测试输入自身标为已用，因此普通池就是 C。每个输入单独作为起点，不表示完整对局；同音起点拥有该词所有可解析音对，后续回合可能只剩其中一部分。

| 指标 | 含义 |
| --- | --- |
| `inputsEligibleForMode` | 此模式能作输入起点的词数；同字包含全部四汉字词，同音要求至少一对可解析音 |
| `commonStartKeys` | 常用表覆盖的首字或全部可解析首音键 |
| `commonWithOrdinaryFollowup` | 作为起点时存在另一个未用常用后继的常用词数，仅作质量诊断 |
| `inputsWithFullDictionaryReply` | 至少有一个未用全库合法回复的输入数 |
| `inputsWithAnyCommonReply` | 至少有一个未用 Common 回复的输入数，不要求该回复再有普通后继 |
| `inputsWithOtherLegalReply` | 存在 Common 之外合法回复的输入数；即使 Common 非空，这些词也可进入探索分支 |
| `inputsWithCommonReplyAndOrdinaryFollowup` | 存在 Common 回复且其后仍有未用 Common 后继的输入数，仅作质量诊断 |
| `inputsRequiringFullDictionaryFallback` | 有全库合法回复、但没有 Common 回复的输入数 |
| `inputsWithSelectableReply` | 当前策略至少有一个可选择回复的输入数，与全库合法回复数一致 |

当前目录版本 `95ef1ff594899efa1f03ac19` 的实测静态结果：

| 指标 | 同字 | 同音 |
| --- | ---: | ---: |
| 具备本模式输入资格 | 45,776 | 45,674 |
| 至少一个全库合法回复 / 可选择回复 | 41,843 | 45,638 |
| 至少一个 Common 回复 | 17,944 | 40,641 |
| 至少一个 Common 之外合法回复 | 41,839 | 45,638 |
| Common 回复后仍有普通后继（质量诊断） | 12,761 | 40,210 |
| 没有 Common 回复，需全库回退 | 23,899 | 4,997 |

102个四汉字词没有可解析读音，仍可用于同字；同音无边不被算成可接。上述回复数允许两类同时存在，因此 Common 与其他合法回复数不能相加当总数。

同音边使用目录第九列的音对；匹配了某对首音，只能沿该对尾音继续，不能跨对拼接。空音对不参与同音索引，多对指向同一词只计一个词；自环和已使用前词不算后继。普通后继为零仅影响轻微权重，不再称为“不合格推荐”。

这些指标是静态覆盖上限，**不是抽中概率、整局完成率、随机开局成功率或用户实测概率**。后续已用词会减少可选集合，个人熟悉词扩大普通范围，生词标记和冷却会改变优先身份。旧报告中的同字 27.87%、同音 87.98% 是旧目录及旧“有普通后继才合格”政策的历史诊断，不能解释为新策略的可回复率。

## 可复跑命令

只需 Python 标准库。审计从打包资源读取，不需联网；基线通过 Git 只读获取，不切换分支或工作区。

```bash
python3 -B scripts/pack-idioms.py --input artifacts/idiom-cleaned-preserved
python3 -B scripts/audit-idiom-common.py \
  --baseline-revision b066953b37bf34328466830b43488a92c853f82f \
  > Data/Idioms/common-coverage-audit.json
scripts/test-idiom-resources.sh
```

`baseline` 是旧 431 词表在**当前新目录与新统计规则**下的结果，不是复刻旧发行包。测试重新计算当前统计并比对报告，防止资源或词表改变后留下旧结果；同时覆盖自环、前词去重、独立字/音索引、全部读音、音对不能交叉、空音对、全库兜底和 Common 非空时仍有其他合法候选。
