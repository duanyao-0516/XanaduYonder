## Android 模拟器操作

仅使用本任务的 `emulator-5586`、Android 36，分别使用 1080×1920 和 1080×2373。测试包为 `com.duanyao.xanaduyonder.idiomtest`，没有覆盖正式应用。本轮用户确认先用模拟器，尚未做物理手机回归。

- 将已有 schema 1 的人机同字／同音局覆盖升级：历史分别为 5／4 条；迁移后逐字段比对历史、提示、草稿、最佳纪录及随机状态不变。
- 双人同字从左方开始，左右各连续提交两次，发送／提示位置随回合镜像；键盘打开时单次点击发送即可提交，交接后草稿清空。
- 双方各两次提示时继续游戏；左方第三次提示即时结算，历史仍为四条，提示分布 3／2，小结显示左方 2 个、右方 2 个。重开当前提示和从详情返回提示不重复计次。
- 双人同音从右方开始，实际完成“高朋满座 → 作法自毙”，验证不同汉字同音可接、说话方交替。
- 非四字输入不提交、不换方；切换字／音和重新启动后四组进度及草稿恢复。中文提示草稿“作法自毙”在 Home／恢复后保留，随后可发送。
- 标题与本轮计数居中，字／音开关位于计数右侧；生词本图标可进入二级列表。新圆形 X 居中，详情内空白不误关闭，外侧阴影关闭并返回正确来源；景墨词库展示正确。
- 大厅、2048、跳一跳、旸了个旸的齿轮和房子入口可操作。生词本和三个游戏的存档在升级及入口回归后逐字节保持不变。
- 最终包日志未匹配到运行异常或成语保存／加载失败。截图、存档快照及日志位于 `artifacts/idiom-local-device/`。

## 后续 UI 验收要求

修改页面标题、计数、图标、开关或弹窗后，必须运行 UI 专项脚本，并审查长／短屏截图。检查几何中心不能代替字形和留白目视检查；编辑器射线测试不能代替跨帧触摸、原生键盘及 Android 安全区验证。物理手机连接后补查系统键盘的左右发送、Home／Back 和长按输入，不将本次模拟器结果当作全部厂商输入法的验证。
