# v0.8.0 Android 发布记录

日期：2026-10-30。本版仍为十七款离线游戏合集，版本 0.8.0 / Android versionCode 8；重点更新大厅、启动交接、合成大西瓜输入和成语接龙。

## 更新内容

- **三种大厅布局**：双列卡片、分类目录、单列大卡，按逻辑策略、合成消除、敏捷挑战、文字语言固定分类与组内顺序排列；点击整张卡片进入游戏。展示方式可切换并记住选择，默认双列；接入统一小图标，单列展示大 Logo 与玩法、真实纪录。王国守卫战和战争进化史仅预留小图标，本版没有新增这两款游戏入口。
- **启动后即可操作**：启动画面等待大厅布局与输入就绪，再同步解除遮挡和触摸拦截；大厅显示后即可滚动和点击，修复可见页面与可交互状态不同步的问题。
- **合成大西瓜贴边投放**：从棋盘内按下，原指拖到左右边界外仍可在正常松手时贴边投放；上下越界释放取消。切后台、失焦或触摸取消后不补投，仍保留原指锁定、冷却和生成空间检查。
- **成语完整词库与原始资料**：四字游戏目录由 42,851 个恢复至 45,776 个，补回 2,925 个词，包含“当仁不让”；按来源分别保留原拼音、释义、典故、出处和例句，生词本保存完整资料。无可解析读音的词仍可用于同字模式。
- **成语接龙继续规则**：全部合法且未使用的词保留选择机会，只有完整词库确无合法接法才自动结束；每名玩家三组提示用尽后仍可继续接词，按钮变为“认输”，双人各自计数。
- **成语气泡与键盘**：新增“发送后收起键盘”（默认开）和“是否显示拼音”（默认关），成功发送后按偏好关闭或保持键盘，无效提交保留输入。气泡随内容收紧并按左右玩家对齐，输入栏与聊天可视区随键盘调整，标题保持固定，查看历史消息时保留位置。
