# v0.9.8 · Android

版本 **0.9.8**，Android versionCode **17**。仅发布 Android，沿用既有正式签名；包名为 `com.duanyao.xanaduyonder`，采用 Unity IL2CPP、ARM64、非 Development 配置。

附件：`XanaduYonder-0.9.8-android-arm64.apk`。同包名、同签名正式版可覆盖升级；独立 `.debug` 包不与正式版共享存档。

## 本次更新

- **Q版泡泡堂初代**：修复两侧控件外缘不响应、方向键切换挤压画面及偏心触摸导致误移动；浮动摇杆首次落指保持中性，增加闲置示意，调整方向圆盘、放弹键和工具栏。修复暂停后计时仍推进的问题；单／双人切换经确认后重新开始游戏。
- **泡泡堂续关与设置**：新增“继续闯关·难度·第 xx/xx 关”，保存关数、难度、角色、剩余生命和累计分，恢复时重新生成本关地图。补齐声音、触感、紧凑设置和玩法说明；说明补充“生命＋1”增加备用生命，被炸仍会退出本回合，可用剩余生命重玩此关，盾牌才用于抵挡一次伤害。
- **贪吃蛇**：方向圆盘作为默认操作方式，可在设置中切回原按键；补齐按压变色，锁定关卡改用锁图标，统一棋盘倒数蒙版。
- **俄罗斯方块**：修复长按下键直落，单指按住 0.5 秒触发一次，保留快速三连击直落。暂停、倒数与新版结算仅覆盖暂存、棋盘和接下来组成的游戏区域，保留查看最终棋盘入口。
- **只有一道门**：选关页返回人数选择页，首屏仍可返回大厅；补齐说明、设置、声音与触感开关，修正设置图标。
- **原生黄金矿工**：合入主线更新，恢复原生矿物美术，按原生矿区重新安排新关布局；矿物回到顶部即记账并继续摆钩。保留经典经济规则，旧存档当前关与检查点不重新摆放，后续新关采用新布局。

## 发布范围

本次包含已完成的操作、续关和界面修复，以及主线黄金矿工更新；**未接入泡泡堂 7**。不构建或发布 iOS，不替换既有 iOS 附件，不更新 Mac 的 iOS 自动续签快照。

按用户要求，本轮发布不追加测试、包体校验或手机验证。既有开发检查记录不代表本次 Release 已通过设备验收。
