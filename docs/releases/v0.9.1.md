# v0.9.1 Android 发布记录

日期：2026-10-31。版本 **0.9.1 / Android versionCode 10**，保留 v0.9.0 的 **19 个大厅入口**。

## 更新内容

修复部分小米 / HyperOS 设备上跳一跳静止长按蓄力后松手无法起跳的问题。系统长按内容识别曾在松手时把 UP 改为 CANCEL；本版在承载 Unity 游戏的 Activity 中声明 `catcher_not_fetch=true`，使系统跳过内容抓取，正常传递松手事件。

跳跃规则、蓄力力度、存档格式和真实触摸取消处理保持原逻辑。配置作用于同一 Unity Activity 下的游戏页面；由独立 Activity 承载的王国保卫战不受此配置覆盖。

## 修复验证

在 Xiaomi 17 Pro、Android 16、HyperOS OS3.0.319.0.WBLCNXM 上，先完成同包的原设置失败 → 临时排除内容识别后成功 → 恢复原设置再次失败的对照，确认根因。随后在保持手机原设置的情况下安装应用侧修复验证包，用户确认静止长按、短点和滑动后松开均正常。

日志记录的五次物理操作均为 Window.Callback UP → Unity Ended → 接受释放 → 单次跳跃提交。两次静止/近静止长按分别为781ms（零移动）及1352ms（1px漂移），另有97ms短点和1499ms、351ms滑动操作。系统同时输出 Activity 不参与内容抓取的日志，证明排除配置实际生效。这里的成功指正常触发跳跃，不代表每次均落到下一平台。

另外通过 ADB 注入原生 CANCEL 和蓄力中切后台验证：取消仍取消蓄力，不提交跳跃；恢复前台无误起跳，新手势可正常提交。此项与用户物理触摸测试分别记录。诊断导出校验通过，55对原生事件无丢失或采集错误。诊断实现仅保留在独立排查分支，不进入本次正式源码与安装包。

发布工作树重新运行跳一跳规则/手势25项、存档18项，共43项检查通过。修复与发布范围经独立源码审查；未对其他机型、其他HyperOS版本及全部游戏关卡做完整回归。

## 安装

Android 8.0（API 26）及以上的 ARM64 设备可安装。沿用既有正式包名 `com.duanyao.xanaduyonder` 和发布签名，可覆盖 v0.9.0 或同包名的本次诊断包并保留存档；无需卸载。
