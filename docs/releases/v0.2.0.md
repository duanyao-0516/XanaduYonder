# v0.2.0 Android 发布记录

日期：2026-10-26。新增第二款离线游戏“跳一跳”，保留原 2048 对局、最高分与公共设置。

## 本次更新

- 大厅双游戏入口，分别显示最高分并恢复各自对局。
- 跳一跳采用斜俯视正交 3D 场景，支持按住蓄力、松手跳跃、随机平台、中心连击、落地与坠落动画。
- 新增独立自动存档、损坏备份恢复、失败重开及后台恢复。
- 修复快速连续操作漏跳：飞行期间可提前按住，落地后释放；蓄力与落地回弹、镜头移动并行。空中短按不排队触发跳跃。
- 共用声音与触感设置；无广告、无登录、无需联网。
