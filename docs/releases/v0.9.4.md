# v0.9.4 · 飞机大战正式接入

本次正式版本包含全部 20 个大厅入口：2048、跳一跳、旸了个旸、合成大西瓜、成语接龙、数独、扫雷、Zuma、Dino、五子棋、欢乐球球、推箱子、黄金矿工、数字华容道、俄罗斯方块、Flappy Bird、连连看、战争进化史、王国保卫战、飞机大战。

飞机大战由 Unity + C# 实现，保留离线游戏内容。从原游戏菜单进入经典或七关模式，并可查看历史成绩；说明与共用设置位于入口右上角，实战保留原素材暂停按钮。支持拖动、自动射击、炸弹、双发补给、普通／疯狂进攻及每局一次免费复活。原包联网、通知、广告、购买和账号服务均未接入。

## 正式安装包

- 文件：`XanaduYonder-0.9.4-android-arm64.apk`
- 应用名：`XanaduYonder`
- 包名：`com.duanyao.xanaduyonder`
- Android versionName：`0.9.4`；versionCode：`13`
- Unity IL2CPP ARM64，非 Development 构建，沿用既有正式签名。
- 发布入口：[GitHub Release v0.9.4](https://github.com/duanyao-0516/XanaduYonder/releases/tag/v0.9.4)。仅上传正式 APK，不附校验和文件。

正式包可覆盖升级同签名正式应用。此前 `.aircrafttest` 测试应用使用独立包名和签名，其数据不会自动迁入正式包。正式包上传后移除 v0.9.2／v0.9.3 的测试 APK，以及 v0.9.4 先前误传的测试 APK，避免将测试应用作为正式版分发。
