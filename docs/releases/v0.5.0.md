# v0.5.0 Android 发布记录

日期：2026-10-28。本次新增扫雷、Zuma、Dino 和五子棋，合集共十款离线游戏。

## 本次更新

- 扫雷：三档棋盘、首击安全、点击翻开与长按 0.4 秒标记，支持 50%～200% 缩放、单／双指平移、全屏和只读总览；各难度独立续局，记录胜负与最佳用时。初级棋盘禁用不需要的全屏和总览入口。
- Zuma：18 张地图 × 4 档难度，横屏拖动瞄准、松手单发与换球，独立保存对局和最佳成绩；新增中文玩法、英文界面对照和难度说明，增强瞄准线可见度。
- Dino：横屏／竖屏可选的像素跑酷，长短跳、下蹲及按住落地续跳，分别保存两个方向的最高纪录；支持暂停倒数、昼夜变化和离线节日装饰。退出对局或重启进程后开始新局。
- 五子棋：15×15 自由规则、人机三档难度和本地双人，支持预选确认、四边坐标、悔棋、换边、暂停及双模式独立续局；电脑思考可随暂停或离开取消。
- 大厅显示全部十款游戏。Dino／Zuma 转向时保留当前画面并冻结旧输入，待新页面就绪后交接，修正跨游戏恢复焦点时的方向干扰。
- 合成大西瓜校徽主题调整顺序，移除中国海洋大学，加入中山大学作为第 11 级；水果、表情主题及合成规则保持原有行为。成语接龙页头统一导航位置，扫雷全屏保留公共存档失败提示。
- 所有游戏无需联网、无账号、无广告。

## 安装与升级

本版继续使用应用标识 `com.duanyao.xanaduyonder`，版本 `0.5.0`、versionCode `5`。已验证与 v0.4.0 使用相同发布证书；从 v0.4.0 覆盖升级的实际检查见下文。

原有六款游戏和公共声音／触感设置的存档协议未因本次新增游戏改变。扫雷、Zuma、Dino、五子棋分别使用 `minesweeper-v1.json`、`zuma-v1.json`、`dino-v1.json`、`gomoku-v1.json`。Dino 只跨进程保存纪录和方向偏好，其余新游戏支持独立续局。校徽素材顺序调整不改变西瓜存档中的等级与物理状态，已有校徽局面会显示对应等级的新图案。

从 v0.3.0 或更早版本升级时，旸了个旸和成语接龙仍遵循[v0.4.0 的迁移边界](v0.4.0.md)：旧羊牌对局、旧成语对局与生词本不自动迁移，旧文件保留。

同包名开发调试包使用不同签名，不能直接覆盖为正式版；卸载会清除应用数据。独立验证包与正式应用可并存，其记录不会自动导入正式版。

本次重新执行全部 39 个非 Unity 检查脚本及 Zuma 资源检查，共 40 项全部通过，覆盖十款游戏的规则、会话、输入、存档、内容与资产；数独题库检查使用 `--bank`，羊牌包含难度模拟。正式签名构建成功，实际 APK 的版本、ABI、权限、签名及对齐已逐项验证。独立测试报告与 APK 审计保存在本地 `artifacts/logs/release-0.5.0/`，不作为公开附件上传。
