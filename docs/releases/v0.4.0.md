# v0.4.0 Android 发布记录

日期：2026-10-27。本次新增数独和合成大西瓜，合集共六款离线游戏。

## 本次更新

- 数独：四档共 2,000 道离线题，支持铅笔候选、快速输入、完整撤回、解题提示和按难度独立续局。
- 合成大西瓜：拖动瞄准、松手投球，同级碰撞合并；提供水果、表情、校徽三种主题，支持最高分和自动续局。
- 旸了个旸：四档挑战、无尽模式、可选热身与独立续局，可设置新局道具次数；优化难度生成，统一教学关与挑战关牌面尺寸。
- 成语接龙：新增本地双人、四组独立对局、个人熟悉词与生词复习，更新选词和对话交互。
- 大厅依次展示 2048、跳一跳、旸了个旸、合成大西瓜、成语接龙、数独；缩减页头留白，将离线与自动保存说明放入卡片滚动区域。
- 2048 卡片改为浅色，显示最高纪录与最高数字；数独卡片显示总完成数和四档完成数。
- 跳一跳与数独统一导航图标；数独使用撤回、橡皮、铅笔和铃铛工具图标，玩法改为居中对话框，进度显示已填写格数/剩余空格数，优化难度菜单颜色与圆角。
- 所有游戏无需联网、无账号、无广告。

## 安装与升级

本版沿用 v0.1.0 至 v0.3.0 的发布证书，支持覆盖升级。2048、跳一跳及公共声音/触感设置保持兼容；2048 新增的最高数字从旧档当前盘面最大值开始记录，无法还原此前已结束对局的历史最高数字。

旸了个旸改用 `sheep-v2.json`，成语接龙改用 `idiom-learning-v1.json`。旧羊牌对局、旧成语对局与生词本不自动迁移，旧文件原样保留。数独、合成大西瓜使用独立存档；曾安装数独开发版本时，新版数独可承接合法的旧单局存档。

同包名的开发调试包使用不同签名，不能直接覆盖为正式版；卸载会清除应用数据。各独立验证包与正式应用可并存，其记录不会自动导入正式版。

## 验证

发布前重新执行 20 组独立检查，全部通过：2048、输入、跳一跳、羊牌、成语、数独和西瓜的规则及存档检查，成语清洗与资源完整性，羊牌 200 局难度模拟，以及数独 2,000 道题的 325,253 项题库断言。

界面修正已通过真实 Unity Play Mode 的 205 项 UGUI、像素与交互断言，以及成语界面的 1,594 项回归断言；羊牌几何检查通过 1,370,322 项断言。此前开发包在 Android 36 ARM64 模拟器验证大厅、跳一跳和数独交互，详见[本轮界面修正验证](../verification-minigame-ui-fixes.md)。
