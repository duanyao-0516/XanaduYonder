# v0.7.0 Android 发布记录

日期：2026-10-28。本次发布目标为最新 master 的十七款离线游戏合集，版本 0.7.0 / Android versionCode 7。

## 更新内容

- 连连看：新增大厅卡片和轻松／挑战选关页，独立竖屏棋盘支持最多两次直角转弯及外圈连线；五关为 24／36／48／96／192 张，使用 48 种 Microsoft Fluent 3D 图案。轻松模式不限时，挑战限时 90／120／150／300／600 秒，含提示、主动洗牌与无路免费重排。两模式各五关独立续局，暂停遮盘；严格承接本应用内已有的 v1 六槽存档。
- 数字华容道：3×3／4×4／5×5 自由拼图及三章共 18 题闯关，支持点击与单块滑动、撤回、计时和连续解锁；自由尺寸与闯关分别续局，记录最少步数及最快用时。
- 俄罗斯方块：竖屏无尽模式，七袋随机、双向 SRS 旋转、Next 3、Hold 和 Ghost；普通消行与软／硬降计分，温和提速，完整对局独立保存，暂停后明确继续。
- Flappy Bird：轻点拍翼、管道计分、暂停与三秒恢复倒数，沿用已确认的小鸟和管道素材及 OPPO 体验调整，独立保存最高纪录。
- 保留 v0.6.0 的十三款游戏和固定高度滚动大厅卡片；新增四款依次追加为第 14 至 17 款，声音与触感继续共用设置。

连连看的设计、素材与 UI 示例见[调研说明](../link-match-research.md)、[48／96／192 张对照](../prototypes/link-match-density/README.md)及[扩关记录](../verification-link-match-expanded.md)。全部素材许可见[第三方说明](../../THIRD_PARTY_NOTICES.md)。
