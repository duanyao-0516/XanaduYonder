# v0.9.0 Android 发布记录

日期：2026-10-30。版本 **0.9.0 / Android versionCode 9**，共 **19 个大厅入口**，新增战争进化史系列与王国保卫战初代。

## 更新内容

- **战争进化史**：一个入口内选择一代或二代，使用离线原素材与 Unity 原生规则。两代各自保存未完成战场，从对应主菜单的 Continue 继续；恢复后停在暂停页。开始页提供玩法说明与设置。
- **王国保卫战初代**：FL 初代 32 关、战役／英雄／钢铁三种模式和 13 位初代英雄，游戏内容完整内置、无需联网下载。提供英雄移动、塔与技能升级等玩法；开始页新增可滑动的中文玩法说明和音乐／音效设置。
- **大厅适配**：新增两个入口均适配双列卡片、分类目录、单列大卡。王国保卫战使用新提供的大 Logo，与 Zuma 同尺寸、同位置；紧凑视图使用统一城堡图标。同步此前 master 的大厅边距修正。
- **保留可玩基线**：王国保卫战沿用用户已验收的完整内容，本次不继续裁剪资源；仅修改开始页并增加一个帮助模块，其余 2,423 个文件与可玩基线逐字节相同，游戏内容包仅增加 4,874 B。
