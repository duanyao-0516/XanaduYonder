## 构建与安装

按[开发说明](../development.md#正式发布-apk)设置四个 `XANADU_*` 签名环境变量后运行 `scripts/build-release.sh`。实际手机可通过 `scripts/install-android.sh DEVICE_SERIAL artifacts/builds/XanaduYonder-0.1.0-android-arm64.apk` 安装。

此前本机开发包使用调试签名，与正式发布签名不同，Android 无法直接覆盖安装。迁移前先保护对局；卸载开发包会清除其本地数据。全新安装与后续使用相同发布密钥的版本不受这一首次迁移限制。
