# v0.6.0 Android 发布记录

日期：2026-10-28。基于最新 master 合并黄金矿工，合集共十三款离线游戏。

## 更新内容

- 黄金矿工：单人竖屏、双人横屏全屏合作，左右半屏分别出钩；各 10 关，移动鼹鼠、携钻动物、商店补给、累计资金目标、检查点重试及双模式独立续局。
- 矿工改用橙/青两套整体六帧动画，手臂、握柄与转机同帧；固定出绳点，轻重物收线节奏不同，九类完整抓钩与物品图统一吊环尺寸。
- 欢乐球球：单指横滑转塔、自动弹跳、缺口连落、三层重击、危险面及后期竖板，保存局面与最高分。
- 推箱子：8 关原创教学和 100 关 Boxoban，四向推箱、连续撤回、重来、自由选关及独立续局。
- 保留 v0.5.0 的十款游戏，大厅继续使用固定高度滚动卡片。

黄金矿工开发中遇到的问题、知识和规范集中在[简要复盘](../gold-miner-development-notes.md)。

## 安装与产物

- 应用标识：`com.duanyao.xanaduyonder`。
- 版本：`0.6.0`，Android versionCode `6`。
- APK：`XanaduYonder-0.6.0-android-arm64.apk`；附件 `SHA256SUMS` 提供实际校验和。
- Unity 6000.3.27f1 / IL2CPP / ARM64，Android 8.0（API 26）及以上。
- 使用既有正式发布密钥，关闭 Development Build、调试和 profiler 自动连接；独立开发测试包的数据不自动导入正式版。
- 原有游戏及公共设置继续各自保存，新增游戏各用独立文件；黄金矿工此前测试的旧挑战沿用原累计目标曲线，新挑战使用调整后曲线。

## 验证范围

用户已确认当前黄金矿工体验没有问题，并明确要求停止全部检验、快速合并和发布。本次合并后不再运行规则、UI、模拟器、真机或升级回归；仅执行构建、签名和发布附件完整性操作。不能将历史测试视为十三款整合版的新一轮测试结果。

停止前黄金矿工已完成资产 595 项、Unity Mechanics 1096 项和 UI 16278 项检查，并检查完整动画帧；OPPO 独立开发包安装成功且 APK 哈希一致。详见[黄金矿工验证记录](../verification-gold-miner.md)。欢乐球球与推箱子既有开发证据分别见[欢乐球球验证](../verification-happy-ball.md)、[推箱子验证](../verification-sokoban.md)。

发布仅上传正式 APK 与校验文件，不上传签名材料、设备存档或内部日志。使用 `gh` 创建并发布 [v0.6.0](https://github.com/duanyao-0516/XanaduYonder/releases/tag/v0.6.0)。
