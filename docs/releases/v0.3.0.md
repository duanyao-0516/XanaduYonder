# v0.3.0 Android 发布记录

日期：2026-10-26。本次新增旸了个旸与成语接龙，合集共四款离线游戏。

## 本次更新

- 成语接龙：同字/同音双模式，机器/玩家双开局，双方本局不重复；内置 42,851 条离线成语，左右对话展示成语和拼音。
- 提示始终免费，每局第三次新提示展示鼓励小结；可点击成语查看词义、典故、出处，加入跨局生词本。双模式进度、草稿和最佳数量独立保存。
- 旸了个旸：教学关和挑战关，多岛错位叠层、随机布局、7 格卡槽三消；移出、撤回、洗牌不限次数，支持一次免费复活。
- 大厅保持固定卡片高度与间距，纵向滚动访问四款游戏；沿用米白与绿色配色。
- 使用 XY 图标和启动画面，保留原图留白。修复成语键盘发送点击丢失、Home/返回键草稿回退，增加坏档归档与当前进度恢复入口。
- 保留 2048、跳一跳及公共声音/触感设置；无需联网、无账号、无广告。

发布前重新运行 279 项自动检查：原有游戏 172 项，成语规则/持久化/清洗/资源 107 项，全部通过。独立源码审查覆盖 Assets 元数据、词库分片校验和、MIT 许可、反射 DTO 保留、正式构建入口与公共生命周期。

成语开发包已在 OPPO PKM110 与 Android 36 ARM64 短屏模拟器验证真实中文输入法、显式发送、Home/返回键草稿、第三次提示小结、生词本、1,001 条历史、断网冷启动与坏档恢复，详见[成语验收](../verification-idiom.md)。旸了个旸前期验证见[玩法修订](../verification-sheep-refinement.md)及[图标留白](../verification-logo-padding.md)。正式包已在本任务独立 Android 36 ARM64 模拟器从 v0.2.0 覆盖升级：2048、跳一跳主档与备份逐字保留；2048 原棋盘/20 分、跳一跳 1 分继续局、关闭声音设置均正常恢复。四游戏入口与旸了个旸取牌正常。正式包还完成以下验证：

- 同字机器开局完成两回合，第三次提示立即小结；同音人先开始完成一回合，计数正确。
- “谋臣如雨”等词的释义、出处与例句完整加载，加入生词本后强制停止/冷启动仍可查看，验证 IL2CPP 正式裁剪下的反射解析。
- 键盘可见时单次发送有效；返回键和 Home 后草稿保留，后续编辑可继续。
- 冷启动后双模式数据与收藏一致；旧 2048/跳一跳四个主档及备份仍逐字不变。
- 从设备提取的已安装 APK 与本页待发布包 SHA-256 一致；两个进程日志未发现崩溃、反射或序列化异常。

当前正式包验证覆盖该 Android 36 模拟器；物理 OPPO 的新功能验证使用同运行时代码的独立开发包。未覆盖全部 Android 厂商、输入法或长期性能场景。

## 安装与升级

正式包使用与 v0.1.0/v0.2.0 相同的发布证书，支持覆盖升级。2048 与跳一跳存档协议保持兼容，新游戏使用独立文件，不重置公共设置。

同包名的开发调试版使用不同签名，Android 不能直接覆盖为正式版；卸载会清除本地存档。成语独立测试应用 `com.duanyao.xanaduyonder.idiomtest` 与正式应用可并存，它的测试记录不会自动导入正式应用。

[GitHub Release](https://github.com/duanyao-0516/XanaduYonder/releases/tag/v0.3.0) 仅附正式 APK 和 `SHA256SUMS`；签名材料、设备存档与构建日志不上传。第三方数据与素材说明见[许可记录](../../THIRD_PARTY_NOTICES.md)。
