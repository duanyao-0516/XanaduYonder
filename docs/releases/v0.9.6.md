# v0.9.6 · Android / iOS

版本 `0.9.6`，build `15`。Android 与 iOS 共用源码和构建入口，按平台选择内容。

## 下载

- **Android**：`XanaduYonder-0.9.6-android-arm64.apk`，正式包名 `com.duanyao.xanaduyonder`，沿用既有正式签名，Unity IL2CPP ARM64、非 Development 构建。
- **iPhone / iPad**：`XanaduYonder-0.9.6-ios-arm64-unsigned.ipa`，应用标识 `com.duanyao.xanaduyonder.iosnative`，Xcode **Release** 配置、ARM64、最低 iOS 15.0。

**iOS 附件是未签名 IPA，需要使用自己的有效 Apple 签名与描述文件签名后安装，不能下载后直接安装，也不是 App Store / TestFlight 分发包。** 如采用 Xcode 官方工具链，可检出此版本源码，运行 `./scripts/build.sh ios` 后，在导出的工程中选择自己的开发团队进行 Release 编译和安装。公开附件不包含本机的个人开发者描述文件。

Android 可覆盖升级同包名、同正式签名的应用；独立 `.debug` 测试包与正式包的数据不共享，使用其他证书签名的同包名旧包也不能直接覆盖安装。

发布入口：[GitHub Release v0.9.6](https://github.com/duanyao-0516/XanaduYonder/releases/tag/v0.9.6)。

## 内容

- Android 包含 **25 个大厅入口**，整合切水果大师、只有一道门、赵云与阿斗、割绳子和经典黄金矿工等内容。
- iOS 包含 **19 个 Unity 原生入口**，暂不打包切水果大师、只有一道门、经典黄金矿工、赵云与阿斗、割绳子和王国保卫战；Unity 原生黄金矿工保留。
- 共用大厅、设置与原生玩法存档；包含 iOS 启动音频输出恢复及声音／触感使用说明。
- 日常构建统一为 `scripts/build.sh android|ios`；平台桥接代码及构建、开发、架构文档已整理。

## 本次发布范围

按用户要求，仅执行打包并通过 `gh` 上传两个 Release 产物，未追加测试、独立成品校验、真机安装或设备回归。构建脚本自身的产物与签名检查保留。旧版本的验证结果不作为 v0.9.6 的重新验收结论。

Android 使用现有 Release 构建入口；iOS 经 Unity 导出后，由 Xcode 的 `Release / iphoneos / arm64` 配置构建，关闭代码签名，再将 `.app` 放入 `Payload/` 封装为 IPA。

本次 GitHub 发布不更新本机已经部署的 iOS 自动续签固定快照，也不改变手机上的现有安装。续签快照更新属于新版设备验收与部署流程，见[自动续签说明](https://github.com/duanyao-0516/XanaduYonder/blob/v0.9.6/docs/ios-auto-renew.md)。
