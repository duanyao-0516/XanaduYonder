# 大厅 UI 第二版

此包用于本轮 UI 评审和后续实现，尚未接入 App。

- preview.html：可打开的完整交互预览。
- design-tokens.json：本版颜色、尺寸与布局决策。
- icons/：23 枚独立 SVG、23 张透明 96×96 PNG、游戏映射、来源和许可证。
- large-logos/：当前项目已使用的大西瓜、Zuma、欢乐球球 PNG，逐字节复用。

## 本版确认点

双列卡片：小图标与名称在第一行垂直居中，对图标补偿 1px 视觉偏移；缩小内边距，下方最多一行简要纪录。

目录：小图标与名称同行，隐藏纪录与玩法说明；略微收紧卡片内边距和页面两侧留白。

单列：仅使用现有大 Logo，不增加标题小图标；成语接龙保持纯文字单列卡。顶部文字格式为“编号 / 分类 / 原玩法标签”，例如“03 / 合成消除 / 层层三消”。

缺少小图标时：使用原创 Switch / Joy-Con 式手柄 fallback-controller，成语接龙已使用同一图。

固定使用当前 App 的奶油底、墨绿文字与强调绿。

固定按分类排列，移除自定义排序功能计划。工具行左侧为静态“全部游戏 · 17 款”，右侧按钮用于切换展示方式，工具行上下间距已压缩。

## 后续接入

图标可直接导入 Unity Sprite，按 icons/README.md 设置透明度、无压缩和无 mipmap。

布局由原生 Unity UI 按本版规格实现，preview.html 是评审与对照材料。

本包不修改游戏逻辑、存档或排序数据。示例纪录仅用于呈现文字密度，不代表设备上的真实进度。
