# 贪吃蛇操作动线

2026-10-28：依据用户“检查整体操作动线”的反馈统一。本文描述当前 Unity 页面行为，取代设计草案中显式开始后再弹暂停的旧流程。规则和存档 schema 不变。

## 用户动作与结果

| 入口 / 动作 | 结果 |
| --- | --- |
| 大厅“开始 / 继续游戏”，全新或进行中的对局 | 直接 3 秒倒计时；已有对局保留蛇身、分数、用时和 sessionId |
| 大厅进入已结束对局 | 展示结算；不自动重开或重复结算反馈 |
| 存档异常提示确认“进入游戏” | 提示确认后按上述进入意图继续；确认前不启动 |
| 再来一局、确认重新开始、重玩关卡 | 新局直接倒计时，清分数、计时、旧输入队列 |
| 下一关 | 直接创建已解锁的下一关并倒计时；不再经过预览和暂停两次确认 |
| 经典难度下拉选项 | 直接恢复该难度的进行局，或新建；六个规则槽分别保存，不再弹非破坏性更换确认 |
| 玩法选择中的经典模式 | 恢复进行局；已结束的槽新开并保留纪录，避免重新选择玩法后弹旧结算 |
| 玩法选择中的障碍模式 | 有进行局则直接继续；没有进行局则展示关卡预览 |
| 手动选择关卡 | 显示地图、目标和边界，开始 / 继续后直接倒计时；覆盖另一进行中的闯关对局仍明确提示 |
| 关卡预览取消 / Back | 返回来源玩法选择或关卡下拉，保持原局；锁定关卡的开始按钮禁用 |
| 玩法选择取消、下拉未改选项便关闭 | 返回打开前状态；此前运行则重新倒计时，此前暂停 / 终局则恢复对应页面 |
| 帮助“知道了” / Back、设置完成 / Back | 同上；不再把所有临时页面返回统一变成额外暂停确认 |
| 取消重新开始或边界切换 | 保留原局、原规则，停在暂停态；边界取消保持原设计明确约定 |
| 手动暂停、运行时 Back | 显示暂停；继续按钮直接倒计时；暂停页 Back 返回大厅 |
| Home | 保存并返回大厅；再次主动进入直接倒计时 |
| 失焦、后台、异常长帧 | 清待处理输入并保持暂停；回到前台仍需主动继续 |

## 代码责任

- `SnakePage.StartOrShowResult` 处理明确进入 / 开始意图；`StartClassic` / `StartCampaign` 仅将 Playing 槽视为可继续对局。
- `ShowCurrentState` 保留“显示暂停或结果”的职责，不能直接整体改成 Resume，否则取消边界变更与系统中断也会被误恢复。
- `CaptureOverlayReturn` 在临时页面暂停前记录来源运行态、sessionId 与 interactionEpoch。离开页面或系统中断会让旧回调失效，切换对局后旧 callback 也不能恢复新局。
- 下拉选择保留 UGUI 的真实销毁时序。返回关卡下拉前等待旧列表淡出销毁；关闭回调只消费一次返回意图，不覆盖已经启动的倒计时。
- `ShowResult` 仅显示结果。声音 / 触感在 `AdvancePointerFrame` 的 Playing → terminal 转换时触发，不因重开结果页而重播。
- `SnakeSession` 仍负责暂停、3 秒倒计时、有效用时及队列；倒计时不计入有效游戏时间。此轮未修改规则或公共 shell。

## 布局

棋盘保持 648×777.6 与完整 20×24 方格。基准 top 从 252 下移至 268，额外高度分配从 0.30 改为 0.45；操作区不变。720×1320 中上下留白约 34 设计单位，720×1582 中约 126，避免空白主要堆在棋盘下方。实际截图、自动化检查和 APK 安装记录见 [实现与验证](verification-implementation.md)。
