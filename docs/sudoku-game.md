# 数独玩法与接入

数独是独立离线模块，包含入门、简单、中等、困难四档，各 500 关。只使用标准 9×9 规则，不包含特殊变体。稳定游戏标识 `sudoku`，题目 ID 为 `se-v1-d0-l001` 等；难度和答案在开发电脑完成计算并随题库发布，手机不重新分档或验证唯一解。

## 玩法

- 普通模式先选格，再选数字。题面只读，玩家数字可擦除、替换、撤回。正式数字与答案不符则保留红字并计错，累计第三错本局结束。
- 铅笔 ON 在固定小九宫位置添加候选；重复点击同一个候选将其删除。与同行列宫内正式数字冲突时拒绝添加、闪动三次、不计错。候选是否等于最终答案不参与判错。
- 正确填数会清空目标草稿，并从关联格中只删除相同数字的候选。撤回恢复整笔盘面变化，包括这些被自动删除的候选；错误数、提示消耗与时间不回退。
- 快速模式先选数字，再连续点空格。可以从底部或盘面的正确数字选数；不会覆盖已有大数字。开启前说明规则，点击已有数字时显示修改方法的轻提示。快速与铅笔可组合。
- 选中格、同行列宫、相同正式数字及同数候选分别高亮。题面深色、玩家正确数字绿色、错误红色；冲突闪动不阻塞继续输入。
- 待填格和每个数字的余量只统计尚未正确完成的位置，不把错误数字或草稿计为完成。只有全盘正确才通关。

## 提示与计算边界

每局三次提示，确认后首次展示才扣一次；生成失败、取消、过期结果不扣。同一盘面可重看当前帮助，定位、解释、揭晓及应用合计一次；实际盘面变化后旧帮助失效。

客户端使用当前盘面的副本在后台任务执行逻辑推导，不使用玩家草稿作为完整候选。支持单值、唯一候选、区块排除、数对、三数组及 X-Wing；一条提示可能先进行多轮候选排除，最终填一格。后台计算初始预算为 200 ms，超过预算或技巧不足时明确提供“直接揭晓”，不伪造推理。推导有取消检查，返回主线程时验证所属对局、请求编号、盘面版本和前台状态，之后才扣次并保存。

本机导入阶段负责全题答案、唯一解、难度分档及结构化消元证据验证。运行时题库仅做格式、范围、答案合法性、题面一致性、版本和摘要校验。加载存档时还核对当前题目与题库原题一致。来源及重建命令见 [题库说明](sudoku-content.md)。

## 关卡选择

难度下拉框在左，当前难度的开始 / 继续按钮在同一行右侧。无进行中对局时从本难度第一个未完成关卡开始；已有对局显示“继续 · 第 N 关”，全部完成后显示“重玩”。关卡和题号保持原题库顺序，每页 50 关，使用图形箭头翻页，并分别记住四个难度的浏览页。

每个难度最多保留 1 场未完成对局，共 4 场。切换难度只切换列表；选择同难度的其他关卡时先确认替换，其他难度和历史完成记录保留。进入盘面就算开始，即便尚未填写也显示进行中。通关或失败后释放该难度的对局位置。

选关页和对局页的设置旁都有书本图标，可打开完整玩法。

## 生命周期与存档

暂停、锁屏、后台及失焦时停止计时、取消尚未展示的提示，以不透明雾层遮住盘面与提示内容；恢复后需点击继续。提示解释等仍显示棋盘的弹窗继续计时；完整玩法页遮住盘面并停止计时，返回对局后恢复。终局停止输入和计时，重开重置本局，历史完成标记保留。

`sudoku-v2.json` 保存四个可空的难度槽、全局通关记录、当前难度和四档浏览页。每个槽保留盘面、候选、整步撤回历史、错误和提示消耗、时间、输入模式、选中位置及已付费帮助。首次升级只在新版主档和备份均不存在时读取 `sudoku-v1.json`，保留原文件；一旦存在新版存档，不再回退复活过期的旧版进度。旧版自动生成且完全未动的入门第一关不视为已开局。

所有变更先确定完整新状态，再原子写盘；主档损坏尝试 `.bak`。单场快照限制 16 MiB，四档文件限制 64 MiB，严格校验字段、类型、槽位难度及完成记录关系；超限或写失败明确显示未保存，不裁剪历史、不覆盖其他游戏存档。

`SudokuGame` 拥有规则，`SudokuControls` 分发四种输入，`SudokuSession` 管理时间与提示接收边界，`SudokuProfile` 管理四档槽位及全局完成记录，`SudokuPage` 和 `SudokuBoardView` 呈现交互。公共 `AppController` 仅增加数独入口、保存和前后台通知，大厅第四张卡继续保持 350 高度、24 间距并滚动。
